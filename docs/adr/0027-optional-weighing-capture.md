# 本厂可配置称重强制抓拍

2026-10-23，用户接受无图记录缺少现场车辆图片追溯依据的后果，并授权实施。部分厂区摄像头尚未施工完成，需要使用真实仪表称重、生成正式单据和打印。本厂配置管理提供“称重强制抓拍”，默认开启；管理员可按既有配置权限关闭。关闭仅放宽图片条件，设备重量、稳定与新鲜状态、操作员核对、本地业务校验和打印结果核实继续适用。

关闭时，未启用摄像头直接采重；已启用时尝试抓拍，抓拍或上传失败可继续，保存实际失败状态及已经取得的有效图片。仪表失稳、重量变化、过期或 Agent 离线仍阻止采集和确认。开关由业务服务决定并随采集请求下发，配置缺失或值非法按开启处理。

每次称重保存当时策略及版本、图片状态和原始重量，工作台、核对及历史明确显示无图事实；不补造图片，不将未来图片回填为原称重证据。配置切换后未确认采样须重新采集，已确认首磅及历史单据保留，回磅按新配置办理；同一任务可包含不同图片状态。关闭期间仍生成正常正式单据并可打印、补打，不额外引入审批或测试单流程。

本决策调整 [ADR 0013](0013-formal-weighing-evidence.md) 的无条件强制抓拍条款，其他证据、权限及业务规则保留。功能规格与验证见[强制抓拍配置](../requirements/optional-weighing-capture-spec.md)。真实摄像头及完整设备闭环仍须独立现场验收。
