# 抓拍默认强制，允许本厂管理员关闭

2026-10-24 有效决定摘要，合并已确认修订，不构成新的业务决策。[原始决定与演进记录](../history/adr/0027-optional-weighing-capture.md)保留来源与历史事实；实现及验收统一见[当前状态](../next.md)。

## 有效决定

本厂受保护布尔项 weighing.capture-required 默认开启。开启时指定抓拍相机集合非空且全部取得有效新图；关闭仍尝试所选相机并如实保存成功图片、失败及无图状态。每次采样保存策略版本，策略变化使未确认采样失效，历史依据不回填。设备重量、人工确认和其他业务校验保持。

## 取舍

允许摄像头未施工或故障时按本厂明确策略办理，接受缺图降低追溯能力的代价；用权限、审计、当时策略及缺图事实使例外可查。摄像头数量按新目标可变，不再固定前后两图。
