# 单厂设备职责与配置归属简化

2026-10-24 用户确认。决策首次产出规格及实施拆分；当前实现与验证统一见[状态入口](../next.md)。需求与验收见[设备规格](../requirements/local-device-maintenance-spec.md)，工程依赖见[实施计划](../history/requirements/local-device-maintenance-plan.md)。

现场 Agent 专注本机串口仪表、打印执行及打印账本，并为称重采集提供仪表有效性检查；网络摄像头配置、独立 RTSP 抓拍、可选识别及 MediaMTX 视频源管理迁入本厂 Server。摄像头数量与名称可变，预览不再限定车前／车后。Server 直接读取摄像头取得正式图片，浏览器经可独立部署的 MediaMTX 使用 WebRTC 预览。MediaMTX 故障不直接阻断直连抓拍。

取舍是让 Server 必须具备摄像头网络访问能力和取帧依赖，换取 Agent 配置、安装和换机的简化。没有采用浏览器截图形成正式证据，也没有要求全部设备配置存入 Server：串口、打印及最后成功配置继续由 Agent 本地持有，Server 只留用于明确恢复的成功配置备份。

按当前单厂单磅、局域网设备互信的范围，Agent 只需 Server 地址即可接入本厂唯一地磅；取消 Agent 密钥、配对文件、人工 Agent 编号和换机重绑。内部业务身份继续保留，同磅先接入者保持连接，后接入者明确冲突，不自动抢占；真实 Agent 与 mock 同样互斥。用户登录、JWT、RBAC、业务归属及维护审计继续沿用，不因设备互信放开用户业务权限。

仪表只开放串口与波特率，固定按当前已核验 D12 `tF=05`、吨制、1 秒无有效数据阈值运行；取消单独启用、协议、源单位和超时配置。该结论仅针对当前核验仪表，不扩展声称所有 D12 或其他固件都按吨输出。打印保留现场校准能力，宽度暂留高级设置。仪表／打印只提供一次“保存并应用”，主进程及维护连接保留，内部完成检查、重载和失败恢复。

Server 内设独立摄像头管理模块，数据存 PostgreSQL，保存即用于后续采集；MediaMTX 同步与直连抓拍分别反馈。强制抓拍开启时所有指定摄像头均须取得有效新图，零台不能绕过；关闭时按实际结果保留图片和缺图状态。采集期间重量、稳定、故障及连接变化不能因职责迁移而被忽略，恢复相同读数不使已失效的本次依据重新有效。采集成功后冻结结果，不再依赖后续设备状态，确认边界见 [ADR 0032](0032-freeze-successful-capture.md)。

本厂名称、地磅名称、单据标题和强制抓拍统一在“系统管理 → 配置管理”维护。本厂身份与资料继续更新原业务表，标题与业务开关使用通用配置；单据标题可自定义。Server 启动参数仍保存在本地配置文件，由安装工具生成。正常安装、升级和网页维护不要求手写 YAML 或 `agent.env`，升级保留现场参数、图片和打印账本。打印未知先核实，任何重连、恢复或换机均不自动重放物理打印。

## 替代范围

- [ADR 0022](0022-keli-d12-serial-integration.md)：替代仪表启用／协议／源单位／超时可配置及 Agent 内相机协作部分；原始帧、小数位、精确吨制表达、稳定与故障规则保留。
- [ADR 0025](../history/adr/0025-camera-stream-maintenance.md)：替代前后两路配置、视频源由部署文件维护以及不使用 Control API 的限制；自由部署、浏览器直接 WHEP 预览及预览不是正式证据的原则保留，不新增播放鉴权层。
- [ADR 0026](../history/adr/0026-agent-owned-device-maintenance.md)：设备参数由 Agent 持有收窄为串口与打印；相机及视频服务配置归 Server；网页草稿流程替换为单次提交，进程常驻与主机恢复边界保留。
- [ADR 0027](0027-optional-weighing-capture.md)：前后各一图调整为本次指定的摄像头集合；强制默认开启、关闭可缺图及策略快照原则保留。
- [ADR 0028](0028-single-local-runtime-identity.md)、[ADR 0029](../history/adr/0029-local-initialization-and-agent-connection.md)：替代 Agent 配对与密钥维护、本厂独立菜单入口等对应条款；单一本厂身份、编号固定及地址不属于厂区业务资料继续有效。人工两名称初始化随后由 [ADR 0031](0031-automatic-local-identity.md) 替换为启动自动建立内部身份。
- [协议 v1](../../protocol/v1.md) 是改造前的实现契约。认证头、相机上传／采集消息及测量窗口需按新规格修订并与 Server、真实 Agent、mock 协同升级；本决策不宣称旧客户端已具备新能力。
