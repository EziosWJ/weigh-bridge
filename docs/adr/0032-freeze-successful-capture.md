# 成功采集后冻结称重依据

2026-10-26 用户确认：采集时检查稳定重量并取得所需抓拍，成功后冻结重量、时间、图片和当时策略，操作员核对确认时不再依赖设备持续在线、稳定或保持同值。此前持续检查使短暂设备变化和无关状态刷新打断核对，且混淆了采集有效性与后续保存；接受车辆下磅后仍可确认已成功保存的依据，改由人工核对与本地业务校验完成正式称重。

替代原确认前再次核实测量代次、设备版本和当前抓拍配置的要求；采集窗口内的设备检查仍保留。确认仍检查权限、操作会话、车牌与任务绑定、任务版本、必填资料及重复使用；主动重采替换旧结果，主动废弃不可提交。规则见[业务规格](../requirements/weighing-business-spec.md#3-重量与称重证据)与[设备规格](../requirements/local-device-maintenance-spec.md#63-抓拍期间的重量依据)，状态见[当前状态](../next.md)。
