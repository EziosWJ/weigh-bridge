# 原始称重与人工扣减分别保留

客户需要在地磅读数偏多时人工扣减毛重、皮重后开单，同时保留原始值可查。逐项访谈已选择：原始称重依据不可覆盖，人工扣减另行记录，最终毛皮净重用于单据及打印；原始称重与最终单据分为独立列表。用户已于 2026-10-17 授权发布 Spec 后完成方案，前端模拟已实现并验证。

此方案保留 [ADR 0013](0013-formal-weighing-evidence.md) 对设备测量证据的约束，将“纠正采集结果”和“调整开单重量”分开，避免直接改写称重值而失去依据。代价是查询、导出和汇总必须明确原始／最终口径，扣减皮重也可能使最终净重增加，不能只保留一组无来源区分的毛皮净重。

已出单后更正扣减通过作废、更正重开生成新单，保留原单及扣减历史；这扩展了此前只允许更正业务信息的重开范围，不允许修改原始称重依据。纸质单只展示最终重量，完整调整记录在系统中追溯。

来源：[访谈 Q1—Q16](../requirements/manual-weight-adjustment-discovery.md)，完整规则及当前前端模拟范围见 [人工重量调整需求](../requirements/manual-weight-adjustment.md)。正式业务与设备能力仍为计划／未实现。

## 2026-10-17 输入方式与单位修订

用户进一步明确：操作员对照只读原始值，直接录入扣减后的最终毛重和最终皮重，默认带入原值；系统按“原始值 − 最终值”计算扣减量，净重自动计算。全部业务重量采用吨，精确至 0.001 吨；显示最多三位小数并省略末尾无效零，例如 5.000 吨显示为 5 吨。沿用只减不加、保留原始依据和作废重开留痕的决策；先前人工输入扣减千克数的交互不再适用。

此次修订已在前端模拟中实现，包含缓存版本升级、旧 kg 来源保留及页面与导出的吨制格式；约定验证记录见 [调整交付计划](../requirements/weight-entry-tonne-plan.md)。上文对扣减量输入方式的结论仅描述旧版实现。
