# 原始称重与人工重量调整分别保留

当前决策以文末 2026-10-18 客户确认补充为准：支持双向调整、操作员处置及单磅重称；允许隔夜卸货后回磅，隔日回磅及作废重开无需审核，人工调整备注选填、默认“磅精度调整”。这些规则已完成前端模拟，正式业务仍未实现；下文保留此前讨论及各阶段交付事实，最新交付见文末。

客户需要在地磅读数偏多时人工扣减毛重、皮重后开单，同时保留原始值可查。逐项访谈已选择：原始称重依据不可覆盖，人工扣减另行记录，最终毛皮净重用于单据及打印；原始称重与最终单据分为独立列表。用户已于 2026-10-17 授权发布 Spec 后完成方案，前端模拟已实现并验证。

此方案保留 [ADR 0013](0013-formal-weighing-evidence.md) 对设备测量证据的约束，将“纠正采集结果”和“调整开单重量”分开，避免直接改写称重值而失去依据。代价是查询、导出和汇总必须明确原始／最终口径，扣减皮重也可能使最终净重增加，不能只保留一组无来源区分的毛皮净重。

已出单后更正扣减通过作废、更正重开生成新单，保留原单及扣减历史；这扩展了此前只允许更正业务信息的重开范围，不允许修改原始称重依据。纸质单只展示最终重量，完整调整记录在系统中追溯。

来源：[访谈 Q1—Q16](../requirements/manual-weight-adjustment-discovery.md)，完整规则及当前前端模拟范围见 [人工重量调整需求](../requirements/manual-weight-adjustment.md)。正式业务与设备能力仍为计划／未实现。

## 2026-10-17 输入方式与单位修订

用户进一步明确：操作员对照只读原始值，直接录入扣减后的最终毛重和最终皮重，默认带入原值；系统按“原始值 − 最终值”计算扣减量，净重自动计算。全部业务重量采用吨，精确至 0.001 吨；显示最多三位小数并省略末尾无效零，例如 5.000 吨显示为 5 吨。沿用只减不加、保留原始依据和作废重开留痕的决策；先前人工输入扣减千克数的交互不再适用。

此次修订已在前端模拟中实现，包含缓存版本升级、旧 kg 来源保留及页面与导出的吨制格式；约定验证记录见 [调整交付计划](../requirements/weight-entry-tonne-plan.md)。上文对扣减量输入方式的结论仅描述旧版实现。

## 2026-10-18 操作员处置与双向调整讨论（待实现，原因规则由文末客户反馈覆盖）

现场没有主管，且测量与开单错误可能需要上调最终值；车辆已卸货时不能重新取得原毛重。用户选择由操作员直接办理人工调整、重称、纠错、终止、作废重开、打印核实／补打及导出，保留原因与操作历史，不新增主管审批。取舍是以原始证据、人员身份、前后值和单据版本追溯承担核查职责，而非用主管专办或只减不加限制现场更正。

最终毛／皮重可高于或低于原始值，超过原始值只提示、不阻止；正数、精度及最终毛重大于皮重的校验保留。原始值不被改写，差额继续按“原始 − 最终”计算，允许负数并明确上调含义。调整原因必填、无需强制附件；无调整时无需调整原因。这覆盖旧版“只减不加、原因选填”的决策。

已出单后先作废，再关联重开，原单及其依据、最终值与调整记录不可覆盖。实际重称可只处理有问题的一磅，核实目标装载状态及另一磅有效后沿用另一磅；历次采集及替代关系保留。无法重采时可有依据地人工更正最终值，不能伪装成设备采集或改写图片。重开可能改变当前有效采集组合，但每张旧单的历史快照保持不变，同一任务只有一张有效单。

上述修订与保留原始证据的 [ADR 0013](0013-formal-weighing-evidence.md) 一致；放开的是最终单据值的调整方向及业务岗位，不是设备原始证据或断网正式出单条件。完整规则与待实施验收见 [补充 Spec](../requirements/operator-weighing-corrections-spec.md)。当前模拟仍有主管限制、只减不加及未出单首磅重称限制；本次仅完善文档，未实施或验证新行为。

## 2026-10-18 客户确认补充（待实现）

客户确认存在过夜车，允许隔夜卸货后回磅；隔日回磅、单据作废及重开由操作员办理，保留记录即可，无需审核。沿用原任务与首次称重，保留两次实际时间及操作人，不新增隔日审批或必填核实说明。

人工调整原因／备注选填，默认文案为“磅精度调整”，可修改；未填写或清空时保存默认备注，不因未自填原因或缺少附件阻止调整。此结论覆盖上节本轮讨论时的“调整原因必填、另行说明依据”要求，保留原始值、前后值、人工来源、人员时间和单据关联。作废／重开无需审核不改变其操作留痕，其他已确认规则继续沿用。取舍是让日常磅精度修正直接完成，以原始数据及操作历史支撑追溯。

上述客户结论已纳入 [补充 Spec](../requirements/operator-weighing-corrections-spec.md) 与 [沟通清单](../requirements/customer-confirmation-checklist.md)，本次仅同步文档，尚未实施新流程。
