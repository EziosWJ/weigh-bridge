# 原始依据、人工最终值与单据版本分别保留

2026-10-24 有效决定摘要，合并已确认修订，不构成新的业务决策。[原始决定与演进记录](../history/adr/0014-manual-weight-adjustment.md)保留来源与历史事实；实现及验收统一见[当前状态](../next.md)。

## 有效决定

保留设备原始值，操作员可双向调整最终毛皮重；差额为原始值减最终值，可为负数，重量统一为吨及 0.001 吨精度。调整备注选填，空白为“磅精度调整”。操作员按权限处理隔日续称、单磅重称、作废与关联重开，无主管审批；原始依据、另一有效磅及旧单快照保留，同一任务最多一张有效单。

## 取舍

现场可能无法重新取得先前装载状态，单向扣减及主管专办限制不能满足纠错。以原始证据、人员、前后值和版本追溯承担核查，代价是查询、汇总和打印必须明确原始／最终口径。终止、重称及作废重开等动作的原因仍单独记录。
