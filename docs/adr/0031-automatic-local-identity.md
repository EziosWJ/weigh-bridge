# 本厂身份自动建立，配置聚焦过磅单标题

2026-10-25：每厂独立部署且仅一台地磅，人工填写厂区名、地磅名不再承担业务选择或打印标题的职责。新业务库由 Server 首次启动事务性建立内部身份，沿用既有表、编号及安装管理员的初始本厂范围；已有身份、授权、停用状态与编号进度不自动改写，身份缺失但已有业务数据时拒绝重建，不清库。

网页退出名称初始化和维护，配置管理突出独立的过磅单标题编辑与样张预览；设备操作留在设备维护，旧本厂称重页退役。标题继续使用原配置权限及单据快照，之后的修改不改变历史票面。替代 ADR 0029、0030 中人工填写两名称的入口约定，其他身份隔离、权限及设备规则继续有效；当前行为见[总规格](../requirements/standalone-site-spec.md)，验证见[当前状态](../next.md)。
