# 日常出单只调整净重，毛重皮重更正限于更正重开

2026-10-29 客户确认：实际业务只扣减最终净重（扣水扣杂），不改写毛重和皮重。本决定取代 [ADR 0014](0014-manual-weight-adjustment.md) 中“初次出单可分别向上或向下调整最终毛重／皮重”的部分；更正重开中的毛重／皮重更正、原始依据保留和单据版本规则继续有效。

## 决定

- 正常二次称重出单的最终毛重／皮重固定为设备原始值；操作员只录入净重调整。最终净重＝最终毛重−最终皮重−净重调整量。
- 净重调整支持按吨（0.001 吨）或按比例（0.01%）录入。比例以调整前净重为基数，折算量四舍五入到 0.001 吨；折算不足 0.001 吨时拒绝。比例和折算后的绝对量都保存。
- 正常出单只能扣减（调整量 ≥ 0）；负数上调仅允许在作废后的更正重开中办理。
- 调整量不为 0 时类别必填、备注选填。类别使用本厂可维护的系统字典 `WEIGHING_DEDUCTION_CATEGORY`，初始为水分大、质量差、杂质多、其他；单据保存类别值与名称快照。
- 更正重开保留毛重／皮重重正能力，并可同时调整净重；最终净重以更正后毛皮重和净重调整量共同计算。
- 纸质票面不新增列：存在净重调整时，净重标签注明扣减或上调量，值仍为调整后净重。Agent 的每行最多 3 字段和 6 行版式不变。
- 历史单据不回写，新增列默认 0；旧毛皮调整单按原字段原样展示。云端载荷升 schemaVersion 3，显式发送最终净重和净重调整字段。

## 取舍

改毛皮重会同时改变票面毛重、皮重和统计口径，无法表达“毛皮都正确但净重扣一笔”的扣水扣杂业务，也容易与设备原始依据混淆。把调整独立到净重后，原始证据、票面毛皮重和净重调整三者口径清楚；代价是新增字段、查询汇总额外列和云端契约升级。

保留更正重开的毛皮更正，是因为车辆离场或无法重新取得装载状态时仍需纠正明显错误的原始值；该能力不进入日常出单，避免被当作常规扣减入口。

## 影响

- 新增 schema migration `00035_net_adjustment.sql`，历史迁移保留；回退需恢复升级前备份。
- 新增 seed `00024_weighing_deduction_category.sql`。
- 正常出单入参不再接受 `finalWeights`；重开同时接受 `finalWeights` 和 `netAdjustment`。
- 云端必须先兼容 schemaVersion 3 再发布厂端，否则含扣减单据的云端净重会偏大。
- 查询、汇总、CSV、票面、单据详情和打印标签同步展示净重调整信息。
