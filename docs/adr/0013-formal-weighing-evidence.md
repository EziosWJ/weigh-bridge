# 正式称重保留设备证据与人工确认

2026-10-24 有效决定摘要，合并已确认修订，不构成新的业务决策。[原始决定与演进记录](../history/adr/0013-formal-weighing-evidence.md)保留来源与历史事实；实现及验收统一见[当前状态](../next.md)。

## 有效决定

正式称重必须有当次有效设备重量、操作员明确确认和本厂 Server 校验。原始测量与时间、人员、图片状态保留；人工调整只影响最终值，不伪造设备采集。抓拍默认强制，管理员可关闭并保存无图事实；互联网断开不阻止正常本地链路，业务或仪表故障不能通过缓存／手输原始值伪造采集；成功结果的冻结与确认边界按 [ADR 0032](0032-freeze-successful-capture.md)。

## 取舍

以可追溯依据减少车辆、重量错配，接受设备故障时暂停正式采集的代价。后续允许人工最终值调整和可选抓拍，但没有放弃原始重量与用户确认边界。
