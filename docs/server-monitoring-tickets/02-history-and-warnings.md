# 02：30 分钟趋势与资源异常提示

GitHub：[#66](https://github.com/EziosWJ/base-project-golang/issues/66)；状态：ready-for-agent。

## Parent

[Spec #64](https://github.com/EziosWJ/base-project-golang/issues/64)

## What to build

ADMIN 可以查看最近 30 分钟 CPU、内存趋势，并在页面观察持续资源不足与恢复。历史由 API 内存保存，首屏只有真实已积累样本，中断留下缺口，API 重启后重新积累。提供后续设备可复用的趋势与状态判断行为，不引入持久时序存储。

## Acceptance criteria

- [ ] 新增只读历史查询并在真实页面展示 CPU、内存趋势；按照时间窗口保留最近 30 分钟，内存有界。
- [ ] 页面关闭后历史继续积累；首屏历史不足照实展示，过期或采集中状态明确，缺口不连成连续曲线。
- [ ] 重复读取相同样本不更新其有效时间或产生伪造历史；各区域按自身有效时间判定过期。
- [ ] CPU、内存 ≥90% 持续 60 秒触发提示，<85% 持续 30 秒恢复；页面说明固定阈值与规则。
- [ ] 采样中断中止对应指标连续时间判断，恢复后重新计时，不把缺口视为连续正常或异常。
- [ ] API 重启清空历史；历史归属当前实例，不写业务数据库、不跨实例共享。
- [ ] 趋势支持按资源和设备标识查询，允许后续磁盘、网络、GPU 切片接入同一行为边界。
- [ ] 用推进时间在 HTTP 行为边界验证 15 秒过期、30 分钟淘汰、阈值持续触发/恢复和精确边界，不等待真实 30 分钟。
- [ ] Playwright 验证趋势、缺口、状态和提示；后端检查及前端 lint/build 通过，同步 API 文档。
