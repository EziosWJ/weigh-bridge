# 04：多文件系统容量与块设备 I/O

## Parent

## What to build

ADMIN 在原生和 Docker 部署的同一面板中，按宿主机挂载点查看容量，按块设备查看读写速率、IOPS 与设备趋势，并在空间接近用满时看到提示。页面明确区分文件系统容量和块设备活动，部分挂载点不可读取时保留其他结果。

## Acceptance criteria

- [ ] 原生和宿主机采集进程均提供多个文件系统及块设备数据，API 与页面按各自设备身份展示。
- [ ] 文件系统展示总量、已用和普通用户可用空间，占用率为已用除以已用与可用之和；Docker 场景对照真实宿主机挂载点。
- [ ] 块设备展示读写速率及 IOPS，用计数差值除以实际采样间隔；首个样本采集中，新增设备或计数重置后重新建立基线。
- [ ] 支持选择块设备查看最近 30 分钟读写趋势，历史、缺口、过期行为遵循公共契约。
- [ ] 文件系统占用 ≥90% 立即提示，<85% 恢复；页面说明容量异常规则。
- [ ] 无设备、不支持、无权限或部分采集失败按区域展示，不将失败值填零，不阻止 CPU/内存等区域。
- [ ] 通过真实 HTTP 路由的确定计数与时间输入验证速率、IOPS、容量比例、阈值边界及设备重置。
- [ ] Playwright 验证多文件系统、块设备选择与异常状态；原生及 Docker 的宿主机采集对照有记录。
- [ ] 后端检查、前端 lint/build 通过，API 与采集部署说明同步。
