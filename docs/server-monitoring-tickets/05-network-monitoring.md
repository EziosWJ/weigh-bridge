# 05：多网卡流量与链路状态

GitHub：[#69](https://github.com/EziosWJ/base-project-golang/issues/69)；状态：ready-for-agent。

## Parent

[Spec #64](https://github.com/EziosWJ/base-project-golang/issues/64)

## What to build

ADMIN 在原生和 Docker 部署中查看宿主机各网卡的收发速率、累计流量、链路状态、错误与丢包，切换设备查看趋势，并按需展示默认隐藏的接口。Docker 场景的网卡必须属于宿主机网络范围。

## Acceptance criteria

- [ ] 原生及宿主机采集进程提供逐接口数据；Docker 端到端验证接口身份和数据属于宿主机而非 API 容器。
- [ ] 各接口分别展示收发速率、累计流量、链路状态、错误与丢包；不直接叠加所有接口流量。
- [ ] 默认隐藏回环和 veth，提供显示全部接口开关；按接口身份切换最近 30 分钟收发趋势。
- [ ] 速率按字节计数差值与实际间隔计算，使用 MiB/s；链路速率已知时分别计算收发带宽占用率，未知时说明支持情况。
- [ ] 首个样本显示采集中；接口新增、计数重置或采集进程重启后重新建立基线，不产生负速率与尖峰。
- [ ] 各接口状态、失败、过期与趋势缺口明确；高流量本身不作为异常告警。
- [ ] 通过真实 HTTP 路由的确定计数和可控时间验证单位换算、带宽比例、重置和部分失败。
- [ ] Playwright 验证多接口列表、默认筛选/全部、趋势切换与未知链路速率；真实 Docker 主机范围验证有记录。
- [ ] 后端检查、前端 lint/build 通过，API 与采集部署说明同步。
