本轮完成文档基线收敛；PostgreSQL 单库收敛已由独立工作完成，见[交付记录](requirements/postgresql-only-delivery.md)。本厂自治和维护整合尚未实施，真实生产尚未切换。此任务列表不构成代码启动、现场操作、提交推送或远程发布授权。

后续收到开发启动指令后，按当前规格验收顺序推进：

1. S1：解除中心配置／初始化依赖，在本厂维护账号、密码、权限与资料，保留本厂隔离及既有业务约束。
2. S2：统一本地发布与启动恢复，确认页面资源、本地数据和设备链路不依赖互联网。
3. S3：逐项完成 D12 非零、稳定判定、摄像头抓拍与识别、正式业务闭环和实物打印现场验收。
4. S4：将设备维护纳入本地系统，统一账号与权限；验证替代能力后退役独立维护服务，形成两个自研进程＋PostgreSQL 的最终部署。

软件维护整合可在现场验收等待期间推进；所有完成状态分别记录软件和现场结果。中心同步、统一账号资料与跨厂汇总暂缓；既有同步代码不作为本期交付前提。
