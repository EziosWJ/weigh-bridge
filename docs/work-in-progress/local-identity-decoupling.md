## 已核对的依赖

- `wb_site`、`wb_scale` 的编码是业务表、授权、设备表外键；查询和操作授权按编码过滤。仅修改配置会导致历史任务无法查询或越过原授权。
- 单号流水号和数据目录水位按厂区编码及日期保存；编码改回旧值时必须继续使用旧水位，恢复数据库时仍需保护。
- Agent hub 以地磅编码索引连接，图片标识包含地磅编码，打印账本目录以 Server 地址、Agent 与地磅编码隔离。修改后要避免旧图片不可读取或切到空账本造成重复打印。
- 当前厂云契约规定编码固定；用户已确认本地可改，云端尚未实现，已绑定后的变更流程需在厂云实现前共同确定。

图片标识解析已限制为合法的编码字符及长度，为后续读取旧编码图片提供安全前提；当前尚未改变图片归属判断。对应单元测试与 `task backend:check` 通过。

本地授权新增 `wb_local_user_access`，迁移既有本厂授权并由账号直接保存操作范围；初始化和授权维护写入新表，旧表暂留用于过渡。旧库授权回填、本厂权限及完整隔离 PostgreSQL 集成通过，后端 test／vet 通过；初次回归发现迁移回退测试失败，改为显式要求恢复备份后复跑通过。本阶段当时编码仍不能修改；没有连接业务库。
