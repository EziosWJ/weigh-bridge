# Agent 参数与局域网维护

适用 ADR 0030 的 Server／Agent v2 软件；实现与验收见[当前状态](../next.md)，安装步骤见[本厂部署](local-deployment.md)。本文维护运行方法，字段和失败语义以[设备规格](../requirements/local-device-maintenance-spec.md)及[协议 v2](../../protocol/v1.md#v2-不兼容变化与升级顺序)为准。旧配对、草稿及 Agent 相机验证存于[原始维护记录](../history/device/agent-remote-maintenance.md)。

## 参数与连接

Server 与 Agent 可同机或本厂局域网分机。Agent 主机持有连接地址、串口与打印参数及账本；Server 通过既有通道转发维护请求、记录用户审计并保存成功参数的恢复副本。业务服务不访问 Agent 主机的文件、串口或 CUPS。

Agent 只需可访问的 Server 地址，无需数据库凭据或配对密钥。未初始化、同磅连接冲突、设备未配置及设备故障分别显示；串口未配置仍保留维护连接。同磅真实 Agent 与 mock 互斥。

维护使用 `/system/agent-maintenance` 及原维护权限。业务地址只读展示，由 Agent 主机工具修改；串口和打印使用一次“保存并应用”。界面区分拒绝、成功、未知、回退和回退失败；未知先读取实际状态，不自动重试应用。

## 设备控制与维护保护

网页启动、停止及重载的是设备执行，Agent 主进程与维护通信常驻。进程完全离线时无法远程读写参数或启动进程，由其主机 systemd／日志恢复。没有在线配置时明确显示离线，不用 Server 文件伪造设备状态。

参数应用与在途采集、确认及打印互斥；维护条件不满足时保留有效参数和当前输入。成功切换后旧未确认依据失效，已提交记录和打印尝试保留。改变打印参数须检查 Agent 主机实际队列与未决作业；维护取消请求不代表已经发出的动作被撤销。

CUPS 队列枚举、队列操作及校准在 Agent 执行；权限准备见[CUPS 与服务权限](agent-local-maintenance.md#cups-与服务权限)。相机、识别、测试和视频配置在 Server 的[摄像头页](camera-live-preview.md)，与 Agent 维护分开。

## 备份与恢复

Server 保留最近生效状态用于诊断；管理员到“设备维护 → 配置备份”手动创建备份，填写名称和备注。只保存 Agent 已核实的生效参数，不包含未应用的表单输入。保存应用、重连和恢复不会自动新增备份；历史自动备份继续可查看、恢复和删除。离线时可查看既有备份，不能创建或恢复。

恢复前查看当前值与备份值的完整对比；由有权限人员明确发起，同时恢复仪表和打印参数，核对新主机串口、CUPS 队列和校准；只恢复设备参数，不覆盖连接地址或设备运行状态。备份数据库及图片，同时备份 Agent 配置、维护数据和完整打印账本。结果未知先核实，恢复或换机不自动补称、出单、打印或重放维护命令。

软件验证证据统一见[新设备交付](../requirements/local-device-maintenance-delivery.md)。真实分机、主机权限、系统服务和实物打印仍按现场结果判断。
