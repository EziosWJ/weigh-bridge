## 已实现

- 独立 `cmd/agent-maintenance` Go 服务，维护页和资源自包含，不依赖 Server；默认回环监听，局域网仅接受私有 IP 并强制 TLS。
- 未登录可读状态、Agent 心跳、云端连接、CUPS/队列状态和未结束作业摘要；维护密码保护配置、完整日志、测试打印、服务/队列动作和操作记录查询。API 每个修改入口独立鉴权，会话 cookie 仅 HttpOnly/SameSite Strict，并做请求来源检查。
- 配置保存在本机文件：草稿、当前生效项、上一份配置分别维护；连接密钥不回显，运行日志和维护记录脱敏。首次密码一次性文件设为 0600，首次登录后删除；管理员可用本机命令轮换密码。
- 固定命令 allowlist，不接受页面自带可执行文件或自由参数；CUPS 解析使用固定 locale。作业快照在执行前复核，快照变化要求重新预览；维护前可选择保留队列或取消所选作业。重启 CUPS 会明确影响范围；CUPS 状态未知时要求显式确认恢复。
- 应用/恢复配置前处理相关队列的未结束作业，保留或部分取消后仍有作业则暂不应用；停止 Agent 后再重新读取作业，写入密钥与配置权限受限的环境文件，启动 Agent 并核验运行状态。CUPS、队列恢复和作业取消也在命令后重新读取状态。配置应用失败恢复原环境与生效项；恢复原 Agent 失败也返回明确错误并留痕，不隐藏在新预览响应后。维护页进程独立，Agent 不可用时仍可操作。
- 离线校准样张每次生成一份固定测试版面，经与业务单据相同的 ESC/P 栅格渲染后提交，标记测试用途。测试不读历史业务任务、不创建业务单、不回写打印尝试和纸面核实结果。
- 宽度、偏移、表长参数进入实际图像/ESC/P 输出；偏移整体平移并保留全部内容，宽度加右偏移不超过 210 mm，向右／向下偏移为 0～30 mm，表长 85～300 mm，按 24 点分带补齐后的实际走纸校验。默认 175 mm、零偏移、99 mm 的栅格和 ESC/P SHA-256 与已确认基准一致。
- 旧根目录打印尝试首次与配置身份绑定，后续 Server/Agent/地磅身份进入稳定隔离目录；URL 大小写、默认端口与尾斜线统一，拒绝查询参数等非协议基址内容，切回身份继续使用原账本。维护动作不删除或重新提交账本。
- 维护事件以本地 JSONL 持久化，逐作业取消包含 Job ID，可按日期、动作和结果筛选后分页查询，历史记录不受最新 500 条截断限制；会话只留 token 摘要，不推出个人身份，不支持导出。

## Review 结论

Standards 与 Spec 最终复审均无未解决阻断项。根代理修复初版中的草稿与生效项混用、校准接口死锁、配置与队列恢复竞态、回退错误处理、校准位移失真／分带越界、等价地址去重绕过、取消目标遗漏及历史查询截断等问题，并加入行为回归；受控验证不能替代现场验收。

## 仍待现场验收

1. 安装用户级维护服务和打印 Agent 服务，确认维护服务在 Agent 失败时可用、Agent 重启和恢复路径有效。
2. 由系统管理员按现场发行版授权固定的 CUPS system service restart，以及所需队列管理动作；确认服务不以 root 运行且没有通用 sudo 权限。
3. 验证私有网卡 TLS、管理网段防火墙、密码首次设置和 OS 本地密码恢复。
4. 用受控非业务作业验收队列暂停、取消和保留策略；确认 CUPS 行为与查询输出符合现场版本。
5. 在 A4 单张与实际连续纸上复核测试样张中文、表格边框、打印宽度、水平/垂直位置及表长。五联清晰度、连续走纸和累积偏移目前均未通过现场验证。
