# 称重工作台视觉、布局与弹窗体验重设计规格（Spec）

> **文档状态**：已实施（软件验证完成，现场待验收）  
> **适用范围**：独立称重工作台 `/weighing/workbench` 及工作台内所有弹窗、抽屉组件  
> **关联基线**：[总规格](standalone-site-spec.md) · [业务规则](weighing-business-spec.md) · [设备维护规格](local-device-maintenance-spec.md) · [后台 UI 主规范](../../web/design-system/MASTER.md) · [称重页面覆盖规则](../../web/design-system/pages/weighing.md)

## 1. 背景与目标

### 1.1 改造前的问题
改造前，独立称重工作台采用深黑蓝暗黑主题、网格光晕背景和荧光青高饱和配色，在持续迭代中暴露出四个核心问题：

1. **视觉风格与后台严重割裂**：全站后台采用明亮、克制、低装饰的浅灰蓝企业规范，而工作台切成了“科技大屏风”（`#06121B` 背景、`industrial-grid.svg` 网格光晕、弹窗径向渐变）。酒厂磅房多为白天强光环境，暗色深底反光发闷；在工作台与后台页面间切换时明暗跳变刺眼。
2. **暗色主题依赖大量 CSS 补丁覆写**：`workbench.css` 约 800 行，通过 `body:has(.weighing-workbench)`、`!important` 和散落的硬编码深蓝灰强行覆写浅色公共组件，导致卡片、输入框、表格灰阶拉不开，满屏硬框线，车牌输入框（`Consolas`）与仪表数字（`Bahnschrift`）字体混搭。
3. **主工作台空间与焦点失衡**：右侧操作区将车牌、识别候选、流转单提示及完整「本趟运输资料」全部塞入第一张卡片，展开后挤压下方本该最醒目的重量仪表（1366×768 下被压至 64px 高度）并触发内部滚动；同时存在多个高饱和主色按钮互相抢戏；左侧多路视频“两小在上、一大在下”反直觉。
4. **弹窗字号倒挂与排布失调**：集中核对弹窗与「查看运输资料」弹窗中，普通业务值被拉到 `28px / line-height: 1.05` 并逐项套盒，单个弹窗内混杂 9 档字号、三层卡套卡；「人工补单」弹窗单列长排且首/回磅重量与时间割裂。

### 1.2 重设计目标
- **视觉基调回归**：回归与全站后台统一的柔和浅灰一体明亮工业风（方案 1），整页收敛在同一明亮舒适域，消除大面积纯黑与纯白碰撞，以**浅金属双层嵌入式仪表盒**作为清晰读数焦点。
- **界面气质定位**：面向**传统高效桌面磅房软件**——极简、大数字、一眼清、零花哨装饰、低认知负担、高频操作顺手。
- **结构与流程清晰**：确立“看车（左侧画面）→ 看数（右上固定仪表）→ 办事（右中车牌与资料）→ 动作（右下唯一吸底主按钮）”的稳定动线。
- **弹窗字号与排版统一**：建立全工作台弹窗统一的克制字号阶梯与表单/清单排版，消除“卡套卡”与巨字撑爆现象。

### 1.3 非目标与红线约束
本次改造**仅调整工作台及工作台弹窗/抽屉的视觉、布局与交互层级**，严格保持以下边界不变：
- 不修改后端 API、数据库结构、Agent 协议、WebRTC/MediaMTX 播放逻辑及打印契约。
- 不改变任何称重业务规则：设备重量依据、稳定校验、车牌人工核对、采集冻结、强制/非强制抓拍策略、净重扣减计算口径、未知提交先查原结果、权限与操作权接管机制均保持原样。
- 不修改后台主框架 `AppShell` 及其他后台页面的样式与全站 CSS Token。
- 保留键盘无障碍（Tab 顺序、清晰 `:focus-visible`、Escape 关闭与焦点还原、尊重 `prefers-reduced-motion`）与 1920×1080 / 1366×768 / 1280×720 / 1024×768 / 390×844 多分辨率可用性。

## 2. 视觉体系规范

### 2.1 色彩方案
- **页面与面板（方案 1：柔和浅灰一体，4 层浅灰阶）**：继承全站浅色 Token（[globals.css](../../web/src/styles/globals.css)），不再使用 `body:has(.weighing-workbench)` 覆写全局背景、弹窗、表格和表单变量。
  - 柔和浅灰白应用顶栏：`#F7F9FC`（底边 `1px solid #D4DEE9` + 轻投影，高 `52px`），搭配柔和浅蓝秤图标底块（`#E6F0FF` 底 + `#1677FF` 图标）、浅绿／浅琥珀 Agent 状态胶囊与清爽白底描边按钮；
  - 工作台画布背景：`#E8EEF5`（柔和雾灰，让柔白卡片自然浮出且不刺眼）；
  - 主面板卡片（监控卡、右侧作业卡）：柔白 `#FCFDFE`，`12px` 圆角、`1px solid #D6E0EB` 配细腻微阴影 `0 1px 3px rgb(15 23 42 / 0.05), 0 4px 12px rgb(15 23 42 / 0.03)`；弹窗、抽屉继续沿用全站标准浅色表面；
  - 文字层级：`var(--color-text-primary)` / `var(--color-text-secondary)` / `var(--color-text-tertiary)`；
  - 主操作色与语义色：沿用 `var(--color-primary)`（`#1677FF`）、`--color-success`、`--color-warning`、`--color-error`、`--color-info`。
- **硬件读数焦点——浅金属银灰双层嵌入式工业仪表盒（`.weighing-instrument`）**：
  - 外层浅金属银灰框：`linear-gradient(180deg, #E2E9F2 0%, #D5DFEB 100%)`，边框 `1px solid #C2CFDF`，圆角 `12px`，内顶部微高光 `inset 0 1px 0 rgba(255, 255, 255, 0.72)` + 轻微外投影 `0 2px 8px rgb(15 23 42 / 0.06)`；
  - 内凹浅雾蓝 LCD 读数显示屏（`.weighing-instrument-screen`）：`linear-gradient(180deg, #ECF1F7 0%, #F5F8FC 100%)`，边框 `1px solid #C3D0DF`，圆角 `8px`，细腻内凹阴影 `inset 0 2px 5px rgb(15 23 42 / 0.09)`；
  - 仪表读数色（双色护眼高对比区分）：
    - 正常实时读数 / 稳定可采 / 已确认：整数深墨蓝 `#0F2942`，小数部分（`.xxx`）与单位 `吨` 采用精工深翠绿 `#0F766E`（配合 `#DCFCE7` 浅绿底 + `#15803D` 深绿字状态胶囊）；
    - 已采集冻结读数：整数深墨蓝 `#0F2942`，小数部分与单位 `吨` 采用深海蓝 `#0369A1`（配合 `#E0F2FE` 浅蓝底 + `#0369A1` 字状态胶囊与干净白底描边「重新采集重量」按钮）；
    - 未稳定 / 离线 / 故障：小数与单位呈沉稳琥珀 `#B45309` 或深红 `#B91C1C`；无有效读数时显示柔和中灰 `#94A3B8`（字重 `500`）的大号 `—`；
  - 仪表辅助文字（标签、上报／采集时间）：`#475569`。
- **明确移除的装饰**：
  - 移除 `industrial-grid.svg` 网格/电路背景；
  - 移除弹窗与抽屉的 `radial-gradient` / `linear-gradient` 光晕底、三层蓝光阴影与 `::after` 内发光描边；
  - 顶栏不再使用 48×48 青蓝发光大图标 `scale-mark.svg`，改用简洁统一的 `lucide-react` 图标（如 `Scale`）配中性标识底块。

### 2.2 字体规范
- **通用文字**：完全沿用后台字体栈 `Inter, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`，全页启用 `font-variant-numeric: tabular-nums`。
- **重量仪表大数字**：`Bahnschrift, "DIN Alternate", "Arial Narrow", "PingFang SC", sans-serif`，`font-variant-numeric: tabular-nums`。
- **车牌输入框**：移除 `Consolas, monospace`，改用统一无衬线字体（字重 `600`，适度字距 `0.04em`），与相邻控件视觉融为一体。

## 3. 主工作台布局与交互规格

### 3.1 顶部状态栏（`WorkbenchShell`）
- **高度与质感**：桌面固定单行紧凑高度 `52px`，柔和浅灰白底（`#F7F9FC`）+ 底部 `1px solid #D4DEE9` 边框与轻投影 `0 1px 2px rgb(15 23 42 / 0.04)`，与主画布自然衔接。
- **左侧（现场身份与实时状态）**：
  - 柔和浅蓝圆角秤图标底块（`#E6F0FF` 底 + `#1677FF` 图标，30px）+ **深灰粗体「称重工作台」**（`#1E293B`，`16px / 700`）+ 副信息 **厂区名称 · 地磅名称**（`#475569`，`13px`，同行展示）。
  - 竖线分隔后展示 **Agent 状态胶囊**（在线浅绿 `#ECFDF5` 底 + `#15803D` 字 + `#BBF7D0` 边；离线浅琥珀 `#FFFBEB` 底 + `#B45309` 字 + `#FDE68A` 边）与操作员账号及角色（`#475569`）。
- **右侧（清爽浅色描边操作区，保留 `nav[aria-label="工作台操作"]`）**：
  - 统一使用 `Button size="sm"`（`32px` 高度）与清爽浅色描边样式（`#FFFFFF` 底、`1px solid #CBD5E1` 边框、`#334155` 字、hover `#EEF3F8`）；
  - **高频业务直达**：`人工补单`（按权限）、`过磅单`、`后台查询`；
  - **异常接管**（仅 `owner === 'other'` 且有权限时出现）：醒目琥珀警告态按钮 `接管操作权`；
  - **会话与窗口控制**（置于最右）：`释放操作权`、`全屏 / 退出全屏`。

### 3.2 主工作区网格（`.weighing-station`）
- **桌面标准布局（`>= 1100px`）**：铺满顶栏下方剩余视口高度（`100dvh - topbar`），外边距与栏间距 `12px`。
  - 左侧现场画面区：`minmax(0, 1.35fr)`（约 57%）
  - 右侧称重作业台：`minmax(400px, 1fr)`（约 43%）
- **桌面视频优先布局（`size === 'large'`）**：保持全宽单列纵向排列，现场画面区占据主要视口高度，作业台自然排在下方并允许页面滚动。
- **平板（`640px ~ 1099px`）与手机（`< 640px`）**：纵向单列堆叠，无横向溢出，不裁剪任何交互控件。

### 3.3 左侧：现场监控与抓拍区（`DeviceCameraPanel`）
1. **工具栏**：柔白底紧凑单行（`44px`），左「现场画面 + 浅蓝实时预览胶囊 + 问号说明」，右「标准 / 视频优先」现代分段开关（浅灰底槽 + 选中白底微阴影）；超过 3 台启用摄像头时，摄像头下拉选择器放在紧凑次行。
2. **多路视频一体化浅钢灰画框（主上辅下，彻底去黑化）**：
   - 多路画面整体收进柔和浅钢灰画框（`#D5DFEB`、`1px solid #C2CFDF`、`10px` 圆角、`4px` 内边距与格子间距，格子自身圆角 `7px`）：1 台全区域铺满，2 台主上辅下，3 台主画面跨上排、两幅辅助画面并排在下。
   - 切换主画面仍只调整网格位置，**不销毁或重建既有 WebRTC 连接**。
   - **断线／重连／连接中／未配置占位态（非 `live`）**：背景采用柔和冷雾灰（`#E5ECF4`），占位图标 `#64748B`、主标题 `#334155`、副说明 `#64748B`，左上角状态胶囊与右下角「放大画面／全屏」按钮采用浅色磨砂胶囊（`rgba(255, 255, 255, 0.88)` + `1px solid #CBD5E1` + `#334155` 深灰字）。
   - **实时视频播放态（`data-camera-state="live"`）**：视频容器背景保持中性深石板灰（`#1E293B`）确保视频留边自然不晃白，左上角状态胶囊与右下角「全屏 / 放大画面」按钮切换为深色半透明磨砂胶囊（`rgba(15, 23, 42, 0.72)` + `backdrop-filter: blur(6px)` + 白字）。
3. **底部抓拍状态与证据条（`.workbench-camera-evidence`）**：
   - 未采集等待态：精致紧凑单行状态栏（高度 `<= 128px`），清晰展示「本次抓拍」+ 策略胶囊（「强制抓拍」/「非强制抓拍」）+ 状态（「等待采集」）。
   - 采集后 / 已保存态：自然展开缩略图横排网格，保留摄像头名称、时间与点击放大预览。

### 3.4 右侧：三段式固定作业台（`.weighing-console`）
将右侧打造为**顶固定（浅金属双层嵌入式仪表盒）+ 中滚动（蓝牌输入、24 小时待回磅队列／指引与本趟资料）+ 底固定（唯一主操作）**的三段式专业磅房结构：

#### 第一段（顶部固定，绝不滚动消失）：浅金属双层嵌入式工业仪表盒
- **外层抬头行**：
  - 左侧阶段标牌：未定位车辆时为柔和冷灰胶囊（`#EDF2F7` 底、`#CBD5E1` 边、`#475569` 字）`待定位车辆`；已定位时为沉稳深海蓝胶囊（`#1D4ED8` 底、白字）**`首磅 · 毛重`** / **`回磅 · 皮重`**。
  - 右侧语义状态胶囊：`稳定` / `已确认`（`#DCFCE7` 底 + `#15803D` 字 + 绿点）、`未稳定` / `设备离线`（`#FEF3C7` 底 + `#B45309` 字 + 琥珀点）、`已采集`（`#E0F2FE` 底 + `#0369A1` 字 + 蓝点）、`设备异常`（`#FEE2E2` 底 + `#B91C1C` 字 + 红点）。
- **内凹浅雾蓝 LCD 读数显示屏（`.weighing-instrument-screen`）**：
  - 左侧：简洁文字标签（`#475569`，`当前设备重量` / `已采集重量（已冻结）` / `本次已确认重量`）+ 冻结且可重采时提供白底描边精工按钮 `重新采集重量`。
  - 右侧：高对比护眼等宽双色大数字（常规桌面 `64px`、`>= 1600px` 为 `72px`、矮屏 `56px`、手机 `48px`），整数深墨蓝 `#0F2942`，小数与单位 `吨` 按状态呈精工深翠绿 `#0F766E`／深海蓝 `#0369A1`／沉稳琥珀 `#B45309`／深红 `#B91C1C`。
- **外框底部元信息行**：等宽展示（`#475569`）`最近上报：HH:mm:ss` 或 `采集时间：YYYY-MM-DD HH:mm:ss`；冻结且设备离线/异常时显示浅琥珀提醒条。

#### 第二段（中部可滚动区域）：蓝牌定位、待回磅队列／空态指引与本趟运输资料
1. **车辆与实体感蓝牌输入区**：
   - 标题行：左「当前车辆」，右简洁状态胶囊（已定位展示任务号或「新趟首磅」）。
   - **蓝牌省份徽章一体车牌条**：省份按钮与车牌号输入收进统一圆角边框（focus-within 蓝光外环），省份已选时呈标志性深蓝实底白字徽章（未选为浅蓝底蓝字），车牌号码为 21px 加粗字；右侧与 `44px` 高度的「确认车辆」按钮对齐（未定位 `primary`，定位后退为 `secondary`）。
   - **识别候选与预查／流转单提示**：候选以轻巧胶囊紧跟输入，预查／流转单提示使用左色条浅底语义卡片。
2. **空闲态待回磅队列／作业流程指引（消灭大白洞）**：
   - 当未定位车辆且无待核实提交时：若场内存在待回磅任务（`status === 'second'`），展示按首磅倒序的**「场内待回磅车辆」**快速点选区（最多 5 条，显示车牌、物料、首磅重、时间；点选仅填入车牌供操作员核对确认，不绕过人工确认）；若无待回磅任务，则展示柔和浅灰底的**「称重作业流程」3 步紧凑指引卡**与设备／抓拍就绪摘要。
3. **本趟运输资料区**（定位车辆或存在任务/待核实时显示）：
   - **首磅录入态**：`SectionTabs`（「基本信息」/「补充信息（选填）」），运输方向使用分段单选，物料和供收方双列并排。
   - **回磅 / 已完成 / 待核实只读态**：细线键值网格直接展示方向、物料、供收方、首次称重依据和可选流转单号，底部保留 `查看完整资料`。

#### 第三段（底部固定吸底）：当前称重操作区
- 固定在右侧作业台最底端，白底圆角卡片，**任何时候仅突出一个明确的主操作**（`44px` 饱满企业蓝按钮带柔和投影，禁用态采用柔和浅灰 `#E2E8F0` 底 + `#64748B` 字）。

## 4. 弹窗与抽屉排版及字号规范

### 4.1 统一字号阶梯（全工作台弹窗强制遵守）
彻底取消 `28px` 常规字段与多层方框嵌套，统一采用 6 档清晰阶梯：

| 层级 | 字号 / 行高 | 字重 | 颜色 | 适用内容 |
| --- | --- | --- | --- | --- |
| 弹窗标题 | `16px / 24px` | `600` | `text-primary` | `DialogTitle` |
| 分区标题 | `14px / 20px` | `600` | `text-primary` | 业务核对、本次抓拍、运输资料、重量与时间 |
| 字段标签 | `13px / 18px` | `400` | `text-tertiary` | 方向、物料、供收方、单号、司机等 label |
| 常规业务值 | `15px / 22px` | `600` | `text-primary` | 物料名、往来主体名、方向、补充信息、备注 |
| 重点车牌 | `22px / 28px` | `700` | `text-primary` | 核对弹窗与资料弹窗顶部车牌 |
| 重点重量 | `28px~30px / 34px` | `700` | 深色主字 / `primary` | 本次采集重量、最终出单净重 |

### 4.2 集中核对弹窗（`WeighingReviewDialog`）
