## 实现范围

- 在现有登录后的侧栏加入「称重演示」，提供工作台、运输任务、测试过磅单、物料及往来单位资料。
- 手填车牌；入厂卸货先毛后皮，出厂装货先皮后毛；净重必须大于零。同车仅一个未结束任务，前车装卸不阻塞其他车辆。
- 集中的浏览器业务状态处理人工核对、采集有效性、演示岗位、占用、重复确认、提交结果不明后的查询恢复；各页面共享同一结果。
- 演示失稳、超时、设备异常、证据失败、断网、未知提交与未知打印结果；配置变化使采集失效，恢复后重新采集和核对。
- 主管可重称、业务纠错、终止、跨天核查、作废及关联更正重开。保留称重原记录、替代关系、原因、操作历史和新旧单关联，同任务最多一张有效测试单。
- 测试单只读预览与模拟打印尝试分开；未知结果先核实，明确未出纸可重试，已出纸或不能排除时需主管原因授权补打，沿用原单号并计次。
- 管理员维护测试物料与供方／收方；已引用资料不能删除，可停用；历史名称保留。
- 任务按北京时间创建日期、单据按北京时间出单日期筛选；支持车牌／编号、方向、物料、往来单位、状态。主管导出筛选明细和有效测试单净重汇总 CSV，包含 BOM、单位、测试标记和字段转义。
- 本模块独立使用 `weighbridge-phase2a-v1` 保存状态，刷新保留，管理员可恢复七个示例任务与两张示例单据。示例包含两方向待二次、待首次、已完成、已终止、已作废及固定跨天待核实记录。

关键入口：`web/src/pages/weighing/`；业务操作与查询：`web/src/lib/weighing/`；共享状态：`web/src/store/weighing-store.ts`。样式与页面结构说明见 [页面覆盖文档](../../web/design-system/pages/weighing.md)。不新增依赖、后端接口、业务表或 migration。

## 简短演示步骤

1. 按根 README 启动现有系统并登录，从「称重演示」进入工作台。新建任务，填写车牌、方向、物料及供方／收方。
2. 展开演示面板设置重量；点击采集，勾选人工核对，再确认首次称重。可以切换其他车辆，稍后回原任务办理二次。
3. 入厂可演示 32000 → 12000 kg，出厂可演示 12000 → 32000 kg；二次后查看测试单，净重均为 20000 kg。
4. 改变稳定、超时、设备、网络或模拟证据状态观察阻断；恢复后重新采集。提交选“实际成功／失败，结果不明”，确认后先查询上次提交结果。
5. 在演示面板切主管；任务详情填写原因重称／纠错／终止。固定跨天示例 `TEST-T-007` 可演示核实说明与主管疑点处理；重称仍需核实装载状态并重新采集。
6. 单据详情可作废后关联更正重开；只读预览检查测试标记与毛皮净重。面板选未知打印结果后，按“主管核实 → 授权补打 → 操作员演示补打”验证记录与次数。
7. 列表筛选后由主管下载 CSV；切管理员维护资料或确认重置本模块测试数据。

## 剩余限制

- 重量、证据、网络、岗位和现场会话占用均为演示状态；摄像头现使用内置示例图片模拟预览和抓拍，无真实现场图像、仪表数据或物理打印任务。真实稳定时长、量程与分度值尚未确定。
- 数据只在当前浏览器保存，不同浏览器不共享，不提供跨终端并发保证、正式证据备份或财务结算报表。保存失败会提示当前进度仅在内存中。
- 登录、JWT、系统管理保持现有实现；演示岗位不是服务端授权。浏览器测试状态不构成正式称重、正式电子过磅单或真实设备验收。
- 正式业务 API、Goose migration、服务端业务授权、幂等与并发、Agent／WSS、真实称重抓拍、设备联调、打印执行及备份恢复仍为后续计划／未实现，须另行确认范围。
