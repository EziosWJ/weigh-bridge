# Spec 补充：操作员处置、双向重量调整与单磅重称

状态：2026-10-18 客户结论已确认，本轮已授权并完成**前端模拟实现和验证**，见 [交付记录](operator-weighing-corrections-delivery.md)。允许隔夜卸货后回磅；隔日回磅、作废、重开无需审核并留痕；人工调整原因选填，默认备注“磅精度调整”。后者覆盖早先“调整原因必填”的约定。正式称重、真实设备及服务端业务仍未实现。未提交、推送、部署或修改远程 Issue。

本文覆盖此前 Spec 中的主管专办、最终值不得高于原始值、人工调整原因必填、隔日单独审核／必填核实说明及出单后不能单磅重称等规则；其他规则继续沿用。客户已确认和仍待核实的项目见 [简版沟通清单](customer-confirmation-checklist.md)。

## 问题与决策

现场没有主管，操作员需要独立办理称重及异常处置，存在过夜车隔夜卸货后续称。测量偏差和开单错误可能要求上调或下调最终重量；车辆卸货或离场后无法重新取得原来的毛重，要求保留有效的另一磅，避免整趟重走。处理方式以保留原始依据、明确来源、操作备注和单据版本留痕为基础，无需主管审批。

### 操作员办理与留痕

- 操作员可办理日常称重、人工重量调整、重称、已确认业务信息纠错、任务终止、隔日回磅、作废重开、打印结果核实、补打及导出，不新增申请／主管审批流程。客户已明确隔日回磅、作废、重开留记录即可，无需审核。
- 所有相关操作保留操作人、时间、操作对象、前后值和关联记录。人工调整原因／备注选填，默认“磅精度调整”，允许修改；未填写或清空时保存默认备注，不因未自填原因或未上传附件阻止办理。未调整重量的正常确认无需填写调整原因。
- 重称、已确认信息纠错、终止、作废、重开及补打沿用各动作已约定的原因记录；人工调整备注与作废／重开的动作原因分开，不把“无需审核”当作删除操作记录。
- 此处仅调整称重业务岗位规则；既有账号、登录、JWT、系统管理及权限契约保持原样。当前前端模拟已完成岗位规则适配；后续正式业务仍复用既有鉴权与服务端授权。

### 隔日回磅与过夜车

允许首次称重后过夜、隔夜卸货后再称皮重，沿用同一任务和已确认首次重量，不因跨日自动终止、清零或要求重走首磅。操作员在正常回磅中核对车辆及任务，系统记录隔日续称、两次实际采集与确认时间、操作人和任务关联，不增加单独审核或必填核实说明。

保留正常车牌匹配、同一运输及有效称重条件。最长间隔尚未约定，本次不增加自动超期阻断；统计归属日期仍按客户清单后续核实。

### 最终重量可双向调整

| 数据 | 规则 |
| --- | --- |
| 原始毛重、原始皮重 | 每次确认的采集结果及其时间、图片、识别依据永久保留；人工录入不能覆盖 |
| 最终毛重、最终皮重 | 操作员分别录入，初次出单默认对应原值；可高于或低于对应原始值 |
| 毛重调整差额、皮重调整差额 | 系统计算：对应原始值 − 最终值；正数表示下调，负数表示上调，零表示未调整。旧版“扣减量”是仅下调时的称呼，不可将负差额截成零 |
| 原始净重、最终净重 | 各自毛重减皮重，均由系统计算；最终净重不能独立填写 |

业务重量继续采用吨、精确至 0.001 吨，显示省略末尾无效零。最终毛／皮重须为有限正数，最终毛重大于最终皮重、最终净重大于零；空白、非正数、非有限数及超三位小数仍阻止确认。

最终值高于原始值时明确提示对应字段及差额，操作员核对后可继续，无须主管审批，也不设置原始值上限；调整备注选填，未自填使用“磅精度调整”。出单前在回磅集中核对时调整；出单后通过作废重开调整。重开时同时展示只读原始值、上版最终值及本版最终值，保留前后快照。

人工调整属于最终单据值更正，须标记人工来源。即使因原读数偏差调整，也不能改写原采集值或图片，更不能把人工输入标为新设备采集。既有实时采集、稳定、抓拍、断网和原始重量业务校验仍适用；本次放开的是最终值上限。已出单后的人工更正沿用留存依据，无须要求车辆回来重新取得另一磅。

### 单磅重称与作废重开

1. 采集失败或尚未确认成功时，重新采集并确认当前这一磅，保留此前有效的另一磅及业务资料。提交结果不明时先查询原结果，防止重复确认或出单。
2. 已确认的某一磅需要实际重称时，操作员指定对应首次／二次及毛／皮含义，说明原因，核实车辆当前装载状态与被替代称重相符，并确认沿用的另一磅仍有效。重新采集、抓拍及人工确认后产生替代记录，旧记录、替代关系及另一磅保留。
3. 未出单时在原任务中完成单磅重称，不重新建立整趟运输；装载状态已改变时，不能以当前重量替代之前状态的重量。例如卸货后的空车不能重称原入厂毛重，但可以重称皮重。
4. 已出单时，先填写原因作废原单，再在同一任务的更正重开流程中办理目标单磅重称或人工最终重量调整，确认后以新单号重开。任务不退回普通首磅流程；新单关联原任务、原单及本次所用称重依据，同一任务最多一张有效单。
5. 另一磅仍有效时直接沿用，无须整趟重走。无法重新采集有误的那一磅时，可按前述规则人工更正最终值，保留原始依据和人工来源标记，备注选填并提供默认文案；人工调整与实际重称分别留痕，不能伪造新称重记录。
6. 每张单据保留生成时采用的称重记录、原始值、最终值、差额和操作快照。后续重称只增加记录，不反向改变旧单或旧打印预览。作废后重开失败时旧单仍作废，不产生有效新单；允许继续办理，重试不得重复出单。已终止任务仍不可恢复。

## 列表、详情与打印

- 保留运输任务、原始称重、最终单据三个页面。原始称重每个完成两次称重的任务仍只有一行，使用当前最新有效的两磅原始采集值；历次组合及替代关系放在详情，不因重开复制任务行。
- 仅人工调整时，原始列表重量及称重日期不变。实际重称可能改变当前有效原始值；原始列表继续按当前有效二次称重确认日期筛选，只重称首次时不改写二次时间，重称二次时使用新二次确认时间，历史时间均保留。
- 最终单据每版本一行，保留有效、作废及关联重开关系，按各版出单日期查询。两份汇总分别使用对应原始／最终净重，只计关联当前有效单的任务，作废排除、重开不重复；原始汇总不因人工调整而变化。
- 详情展示原始值、上版最终值、本版最终值、调整差额、人工／重称来源、原因、操作人和时间；可查看目标重称及沿用另一磅的依据。增加动作时复用现有页面与详情入口，客户重点核实展示字段、查询条件和常用操作，列顺序等界面细节后续设计。
- 原始／最终明细和汇总继续分别导出，导出全部筛选结果。新增双向调整与单磅重称信息应保留其含义，旧数据不得伪造历史原因或身份；旧正向扣减记录沿用“原始 − 最终”的差额符号。
- 打印继续使用对应单据版本的最终毛皮净重；旧单内容不随重开变化。打印结果未知先核实，已打印或不能排除出纸时，由操作员说明原因后补打，保留次数及记录，沿用该版单号。

## 验收示例（前端模拟已验证）

| 编号 | 行为与预期 |
| --- | --- |
| OC01 | 操作员直接办理调整、重称、纠错、终止、隔日回磅、作废重开、打印核实／补打及导出，无主管切换或待审批状态；相关原因／默认备注和留痕保留 |
| OC02 | 原始毛／皮重 30／9 吨，人工更正最终皮重为 10 吨：提示上调后允许确认，最终净重 20 吨、皮重差额 −1 吨；原始值及抓拍仍为 30／9 吨 |
| OC03 | 最终毛／皮重 31／10 吨高于原始 30／9 吨时，分别提示但允许办理；正数、精度和最终净重校验仍阻止非法输入 |
| OC04 | 调整值不同时，无须自填原因即可确认；未填或清空备注保存“磅精度调整”，自填内容如实保留；未调整时不要求调整原因，原始值、前后值和人员时间仍保留；作废及重开各自的操作原因沿用既有规则 |
| OC05 | 首次毛重 30 吨有效，回磅皮重确认前失败：只重新采集皮重，不重复任务或毛重记录 |
| OC06 | 已出单后皮重 9 吨有误、车辆仍空载：作废原单，只重新采集皮重 10 吨，沿用有效毛重 30 吨，关联原任务及原单重开；旧皮重与替代链保留，旧单不变 |
| OC07 | 同例车辆已离场：操作员人工更正最终皮重为 10 吨并重开，调整备注可沿用默认“磅精度调整”，不要求再称毛重，不生成伪造的皮重采集记录 |
| OC08 | 车辆已卸货时阻止以空车重量替代原毛重；只重称皮重仍可办理，沿用另一磅前必须确认其有效 |
| OC09 | 只人工重开时原始行不增、原始值及日期不变；实际重称更新当前有效采集值但保留旧快照。跨日重开／重称按各自日期筛选，汇总排除作废且不重复 |
| OC10 | 出单、重开及重称提交重复或结果不明时先查询／沿用原结果；失败不显示新单成功，刷新后仍能追溯各版重量、单据与原因 |
| OC11 | 首日入厂确认毛重 30 吨，过夜后卸货，次日确认皮重 10 吨：沿用原任务与毛重，净重 20 吨，无需隔日审核或额外必填核实说明；两次实际时间、隔日续称和操作人员记录保留 |

实施时按项目约定选择现有称重行为测试及少量浏览器流程，覆盖上述边界，并运行受影响模块规定检查。本轮通过核心行为测试及少量浏览器流程验证上述规则，覆盖方式和实际限制见交付记录；不代表正式设备或服务端验收。
