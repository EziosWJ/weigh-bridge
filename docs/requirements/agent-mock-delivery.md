# Agent 接口与独立 Web mock 交付记录

2026-10-19，依据 [Issue #3](https://github.com/EziosWJ/weigh-bridge/issues/3) 和 [Spec](agent-mock-issue-spec.md) 完成工作区实现与可执行验证。未执行 Git 提交或推送。真实仪表、摄像头识别、RTSP 视频及物理打印驱动仍未实现和验收。

## 已实现

- [协议 v1](../../protocol/v1.md)：Agent 配置认证、WS/WSS 连接、重量与稳定／故障状态、车牌候选、图片上传、采集及打印命令与结果、心跳及最小重连。
- 独立 mock 程序及 Web 控制台：每 500ms 上报，模拟上磅持续 4 秒波动后稳定；支持下磅、失稳、故障、连接控制、错误候选／识别失败、图片替换及手动打印回执。可在没有 Server 配置、数据库及 JWT 的目录中独立启动。
- 工作台实时读取 Agent 状态，由操作员采集、核对并确认；前后抓拍绑定本次采集，失稳、故障、重量变化、断连和过期使未确认依据失效，稳定恢复不复活旧依据。
- 系统统一处理数据来源，新单据使用正常流程及 GB 编号；原测试单号、快照和图片保持历史含义。
- 移除系统设备模拟设置、浏览器生成识别／采重、旧测试采集 API、测试模式门控及测试专属权限。原浏览器模拟引擎和历史行为测试移至测试夹具，不进入系统运行代码。
- 图片使用独立证据目录及用户鉴权读取；新采集不使用系统内置演示图，原静态图保留用于旧快照。
- 打印先保存尝试再下发 Agent，成功／失败回执去重并记录业务事件与审计。未知结果不自动重打，保留人工核实和补打。
- 修正后台页沿用独立工作台窗口名称的问题；实时设备刷新或同版本详情刷新不再误判人工更正依据已变化，任务版本和重称样本仍受校验。

## 环境限制与迁移

`task db:check` 已尝试，PostgreSQL 集成因当前 WSL 无法使用 Docker 而失败，未标记为通过。SQLite 已修正旧 seed 数量断言并完整通过。V1.0 Server 部署仍使用 PostgreSQL，部署前应在可用 Docker／PostgreSQL 环境补跑门禁。

schema 00012 放宽 Agent 来源、统一单据模式、打印回执来源及编号类型约束。SQLite 通过保留原行和索引的事务性重建完成，并校验外键；seed 00007 移除两项旧模拟菜单／权限。为避免破坏 Agent 历史，00012 Down 不收紧新值约束，00007 Down 不恢复旧模拟入口；继续回退原业务 schema 时仍可删除相关表。原历史 migration 未修改。

默认图片目录为 Server 工作目录下的 `data/agent-images`，已忽略 Git，须与业务数据库一起备份、迁移和恢复；当前不自动清理证据文件。

## 使用

见 [启动说明](../../agent/README.md)。API 与 mock 配置同一 Agent 编号、地磅及本地连接密钥后，分别运行系统开发入口与 `task agent:mock`；mock 控制台默认 http://127.0.0.1:8090。

## 2026-10-19 启动配置修复

直接运行 `task agent:mock` 曾因旧 `task init` 不生成 Agent 密钥而退出。已修复初始化：新配置生成独立随机 Agent 密钥，旧配置只补齐缺失或空密钥，保留其他配置和注释；重复执行不轮换已配置密钥，不在输出中打印密钥。已有 API 需重启读取补齐后的配置。验证包含初始化两种数据库、旧配置补齐、配置保留及实际 mock 启动。

## 2026-10-19 API 端口跟随

mock 不再固定连接 8080：有可用本地配置时自动从 `http.address` 推导 API 地址，通配监听地址转换为回环地址；`--server` 仍可覆盖远程地址，启动日志显示实际目标。已覆盖 `:8900`、IPv4／IPv6 通配地址及明确主机地址的回归测试。
