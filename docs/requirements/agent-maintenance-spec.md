## 目标与部署边界

维护人员可通过现场 Agent 电脑上的 Web 页面配置和维护打印能力，现场操作员可查看状态和排障摘要。维护页支持本机及同一局域网访问，不开放公网；页面资源和维护接口不依赖云端在线。

维护入口独立于打印 Agent 进程。打印 Agent 停止、崩溃或配置错误导致启动失败时，仍可使用维护页查看日志、修正配置并启动它；维护服务自身故障通过系统工具处理。

现有后台保留 Agent 状态展示及正式单据打印、补打、结果核实等业务入口。首期不增加从云端远程配置或控制服务的能力，不要求云端后台直接访问 Agent 的局域网地址。

## 访问与身份

| 使用方式 | 可用功能 |
| --- | --- |
| 未登录／现场操作员 | 只读状态与排障摘要 |
| 通过本地维护密码验证 | 完整日志、配置修改、维护动作、测试打印、维护记录查询 |

本地维护密码独立于后台账号，断云可用；首期不做多用户管理。共用密码只能说明维护会话，不能据此认定具体人员身份。维护权限须在接口执行处校验，不能仅隐藏按钮。

密码及 Agent 连接密钥不得在只读页面、日志或操作记录中明文展示。初始化及密码遗失恢复方式在部署设计中明确，不依赖云端登录。

## 页面功能

### 状态与诊断

- 分别显示本地维护服务、打印 Agent、云端连接、CUPS 服务及目标打印队列状态。
- 显示当前打印机／队列、未结束作业、最近错误及可用于排查的摘要；维护人员可查看完整运行日志。
- 标明最近检查时间；查询失败或无设备反馈时显示未知或不可读取，不将旧状态持续显示为正常。
- 区分队列可接收、作业已提交／完成、现场确认纸面结果。CUPS 完成不代表纸面合格。
- 状态只表达实际可获知的信息；仪表和摄像头未接入时保持未接入，打印可用不代表可正式称重。

### 配置

| 配置组 | 首期范围 |
| --- | --- |
| 云端连接与身份 | Server 地址、Agent 编号、地磅编号及连接密钥 |
| 打印目标 | 选择本机已有 CUPS 打印队列 |
| 打印校准 | 打印宽度、水平偏移、垂直偏移、连续纸表长 |

校准以当前已验证参数为默认值，页面用毫米表达对应尺寸。业务字段、重量、单号和单据内容仍由 Server 决定，本地校准只影响设备输出位置及尺寸。新增打印机、安装驱动不在“选择已有队列”的范围内。

本地身份配置必须与 Server 现有映射一致，修改本地配置不自动更改 Server 身份或权限。不开放打印尝试记录目录的任意切换来规避历史去重；更换身份或 Server 后仍需正确保留并区分原有尝试记录。

配置先保存，再由维护人员明确应用。保存不自动中断服务；界面区分已保存和当前生效配置。应用前先处理目标队列中排队或执行中的作业，应用期间暂停接收新打印请求，不能静默丢弃请求。应用完成后展示实际状态；失败时本地维护页仍可用，并允许恢复上一份配置。恢复配置不清除或重提打印尝试。

### 服务与队列维护

提供明确动作，不使用笼统的“一键复位”：

| 动作 | 行为边界 |
| --- | --- |
| 启动／重启打印 Agent | Agent 已停止时可启动；重启或重连不重提旧打印尝试 |
| 重启 CUPS | 展示本机使用该服务的打印队列及受影响作业，说明影响范围 |
| 恢复暂停的目标队列 | 明确恢复后保留的旧作业可能继续出纸 |
| 取消选中作业 | 仅处理明确选中的作业，保留尝试记录；不据此断言此前未出纸 |

恢复队列或重启服务前，先展示受影响的未结束作业，由维护人员选择保留并继续，或取消指定作业。不能自动清空队列、复制或重新提交旧任务，也不能自动把正式业务的未知打印结果改成已打印／未打印。执行前核对当前作业状态，执行后展示实际结果，不能将命令发出等同于成功。

首期不提供恢复出厂配置、打印机硬件复位或清除打印尝试记录。对服务管理所需的本机权限采用明确的动作授权，不提供任意系统命令执行入口。

### 校准测试打印

- 云端断连时仍可执行，每次打印一份固定样张，明显标记“测试／校准”。
- 用于核对中文、表格、宽度、偏移及表长，使用当前明确的校准参数。
- 不读取本地历史业务任务重新打印正式单据，不生成正式电子过磅单，不增加或修改正式单据的打印次数。
- 测试作业与正式业务作业可区分，测试不隐式恢复暂停队列或清除旧作业。提交与实际纸面效果分别展示／核实。
- 参数可调不代表五联效果或连续走纸已验收，仍需使用真实纸张验证。

### 维护记录查询

本地记录配置变更、服务启动／恢复、作业取消及测试打印的时间、维护会话／访问来源、目标、操作内容和执行结果。配置变更可查询脱敏前后值；不记录明文密码或连接密钥。

维护人员可在页面查询记录，并按时间、操作类型及结果筛选。运行日志与维护操作记录分别展示；维护记录在进程重启后仍可查询。首期不做诊断包、日志或维护记录导出。

## 验收场景

| 场景 | 预期结果 |
| --- | --- |
| 本机及局域网访问 | 能打开本地维护页，资源和接口无需云端可用 |
| 未验证维护密码 | 只能查看状态和排障摘要，直接调用修改接口也不能执行维护 |
| 云端断连 | 可本地登录、诊断、修正配置和打印测试样张；仍不能正式称重确认或出单 |
| 打印 Agent 停止／无法启动 | 维护页仍可用，可查看原因、修正配置并启动 Agent |
| CUPS 停止 | 页面显示异常，维护人员可执行恢复并看到结果 |
| 暂停队列中有旧作业 | 恢复前列出作业并明确保留／取消选择，不自动清队列或重提任务 |
| 配置保存但未应用 | 当前运行配置不变，页面明确显示尚未生效 |
| 有作业时应用配置 | 先处理排队／执行中作业；应用期间新打印请求不会被静默丢弃 |
| 新配置无效 | 维护入口保留，可查询错误并恢复上一份配置；尝试记录不变 |
| 重启或重复打印请求 | 已有打印尝试不重复提交，不因更换连接配置绕过去重 |
| 取消或 CUPS 完成作业 | 不自动修改正式单据的纸面核实结果 |
| 离线校准打印 | 只输出一份明显标记的样张，不改变业务单据、打印次数或补打规则 |
| 校准参数调整 | 宽度、偏移和表长按设置输出；默认参数保持当前已确认版面，真实纸张效果另行验收 |
| 查询维护记录 | 可查时间、来源、操作及结果，重启后记录仍在，敏感值已脱敏，无导出功能 |

实现后运行受影响的 Go／Web 检查和必要的行为测试；对页面做本机／局域网、断云、Agent 停止、维护操作的浏览器验证。实物打印和恢复旧队列的验证使用受控测试作业，并记录实际纸面反馈；未经现场验证的项目不得写为通过。
