## 目标与范围

根据现场反馈，解决启动参数与配置页不同步、局域网访问配置繁琐、服务与队列操作缺少列表及交互引导、所有功能集中在一页的问题。改版对象为 Agent 本地维护控制台；浏览器管理系统的导航及业务页面沿用既有职责。

同一改版完整交付以下范围，分两步验收：先配置同步与网络绑定，再页面导航、服务队列及设备状态页。仪表和摄像头原始诉求中的实际参数配置、实时重量与视频预览，经最终确认延至设备驱动阶段。

## 配置来源、升级和生效

- 打印 Agent 受维护的运行配置统一以 `agent.env` 为来源，包括 Server 地址、Agent 编号、地磅编号、连接密钥、目标队列及打印校准参数。维护页展示当前生效项与待应用差异，密钥仅显示已设置状态，不回显明文。
- 发布的打印 Agent systemd unit 移除与环境文件重复的运行参数。旧 unit 自定义参数通过升级说明人工迁入环境文件；不新增任意 unit 启动命令自动解析机制。升级说明须提供旧参数到 `WEIGHBRIDGE_*` 等对应环境项的示例，使用占位符，迁移后核对实际生效值。
- 迁移保留有效 Server／Agent／地磅身份及密钥，保留打印尝试记录。不能因替换 unit、首次导入或回退而静默套用默认身份、丢弃历史或重提旧作业。
- 配置表单按字段使用输入框、已有队列选择及明确的校验反馈。页面区分已保存、待应用与当前生效状态；按参数实际影响说明生效方式，无需重启的变更即时生效，需要重启的先确认影响再执行。
- 打印运行参数的应用继续遵循相关队列作业检查与既有恢复规则；保存草稿不表示已应用。涉及维护服务自身监听／TLS 等需要重启的变更时，先提示连接影响，重启后页面尝试恢复连接并显示实际结果；失败或不可达时不能显示成功。

## 局域网访问

默认监听 `0.0.0.0`，HTTP 可直接用于可信的地磅房维护网段；允许改回 loopback，TLS 为可选配置，不因非回环监听强制启用。部署说明及 unit 示例须同步更新，并写明防火墙仅允许维护网段来源、不得开放或转发至公网。

用户接受 HTTP 下维护密码与会话未经加密的风险。本地密码验证、接口权限检查、只读访问范围、敏感信息脱敏及维护记录沿用首期约束。此决定不改变 Agent 到 Server 的通信契约。

## 顶部导航与页面分工

| 顶部菜单 | 内容与交互 |
| --- | --- |
| 总览 | 本地维护服务、打印 Agent、云端连接、CUPS 与目标队列状态、最近检查时间和排障摘要；未知或查询失败明确展示 |
| 打印与队列 | 服务状态和对应操作、本机队列列表、未结束作业列表、校准测试打印；具体影响通过操作弹窗展示 |
| 设备 | 仪表和摄像头各自的页面或分区，只显示未接入／暂无预览及能力说明 |
| 配置 | 云端连接与身份、目标队列和打印校准配置，区分待应用项与当前生效项，展示保存／应用结果 |
| 记录 | 分别展示运行日志与维护操作记录，延续首期查询、筛选与分页能力 |

页面切换不再依靠浏览同一个长页面。未登录可查看首期允许的状态与排障摘要；完整日志、配置及维护动作仍需要本地维护密码。

## 服务、队列与作业交互

列表展示本机所有 CUPS 队列及其状态；作业列表仅聚焦未结束作业，显示所属队列、作业编号、提交信息及选择控件。队列和作业的空状态、加载失败与不可读取状态应有明确反馈。

| 操作 | 页面交互与边界 |
| --- | --- |
| 启动／重启打印 Agent | 对应服务行提供操作；重启前展示受影响作业及处置选择，执行后核实实际服务状态 |
| 重启 CUPS | 弹窗列出本机受影响队列与未结束作业，说明可能继续出纸，维护人员确认后执行 |
| 恢复暂停的目标队列 | 仅目标队列提供恢复操作；先列出保留作业，明确继续出纸影响及取消指定作业选择 |
| 取消选中作业 | 必须明确勾选作业；弹窗展示所选目标、取消影响及确认操作，执行后逐项反馈并刷新列表 |
| 校准测试打印 | 明确当前参数和每次一份的固定测试样张，反馈提交结果；实际纸面效果仍需人工核对 |

不增加任意队列暂停／启用、清空队列、业务作业重试或自动重提。执行前的作业快照复核、状态未知确认、配置应用前清理未结束作业的既有规则继续适用。取消、重启或 CUPS 完成均不自动改变正式业务单据的纸面核实结果。

## 设备页的最终边界

本次只交付仪表／摄像头页面框架与真实的未接入状态，不提供可保存但无驱动消费的参数表单，不展示演示重量、模拟视频或伪造正常连接状态。D12 仪表参数、采集与实时重量／稳定状态预览，以及摄像头 RTSP 参数、连接及实时视频预览，均延至设备驱动阶段。

浏览器工作台的最近上传图片依赖 Server API，不作为本地断云维护的预览来源。本次不新增依赖云端的设备图片预览功能。

## 分步验收

下表为验收要求。受控软件验证与现场待验收项目的实际结果见[改版交付记录](agent-maintenance-revision-delivery.md)，不能据软件验证认定现场通过。

| 步骤 | 场景 | 预期 |
| --- | --- | --- |
| 一 | 旧 unit 配置升级 | 按说明迁入旧参数后，打印 Agent 使用值与维护页生效值一致；原身份、密钥及尝试账本保留 |
| 一 | 保存／应用配置及进程重启 | 待应用状态明确，必要重启前有确认，执行后读取实际状态；应用失败仍可维护和恢复 |
| 一 | 默认 LAN 访问 | 默认 `0.0.0.0` + HTTP 可访问，不要求证书；本地维护鉴权仍有效，可选择回环监听或 TLS |
| 一 | 网络部署说明 | 明确可信维护网段、防火墙来源限制及 HTTP 明文传输边界，旧强制 TLS 要求有修订说明 |
| 二 | 顶部菜单 | 五个菜单对应独立页面内容，状态、打印、配置与记录不再全部纵向堆叠 |
| 二 | 多队列与未结束作业 | 列出全部本机队列，作业归属清楚；空列表、查询失败和未知状态可区分 |
| 二 | 维护操作 | 确认弹窗列明作用对象和影响，作业逐项选择，执行后核实并反馈实际结果；不自动清队列或重提 |
| 二 | 仪表／摄像头页面 | 显示未接入及暂无预览，无无效可保存参数；断云可用，不调用云端图片冒充本地预览 |

受影响代码实施后按根指导运行相应检查及必要行为验证；现场 CUPS 权限、局域网访问、恢复旧队列和实物纸张效果单独记录实际验收结果。
