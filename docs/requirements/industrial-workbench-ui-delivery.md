# 地磅称重工作台工业现代 UI 重构

日期：2026-10-19。范围：现有 `/weighing/workbench` 前端展示与交互，不涉及后端、数据库、权限配置及 API 契约。

## 实现

- `web/src/pages/weighing/workbench-shell.tsx`：称重标志、Agent 在线状态、当前用户和岗位、后台查询与原有全屏／释放操作权入口，增加键盘跳转链接。
- `web/src/pages/weighing/workbench.tsx`：左侧现场图片、右侧车牌／称重／采集、运输资料大弹窗；保留全部基本与补充字段、人工车牌核对、资料查询及集中核对。区分设备离线、异常、未稳定及确认状态，无有效设备重量显示“—”，采集中禁用按钮并显示加载反馈。
- `web/src/pages/weighing/camera-panel.tsx`：保留三档画面大小、放大预览、抓拍与图片证据；新增 Agent 前后视角切换及无图片占位。始终明确最近图片不是实时视频；没有上传图时不允许放大空画面。
- `web/src/pages/weighing/workbench.css`：近黑蓝／石墨蓝、青蓝操作和读数、绿色正常／琥珀警告，克制边界、紧凑表单、响应式布局与清晰焦点。主题仅作用于工作台及当前 Portal 弹窗，后台保持原主题。
- `web/public/weighbridge/`：从用户素材包整合称重 SVG 标志和工业网格；来源见该目录 README。素材包生成的车辆图片未用于设备画面。
- `web/design-system/pages/weighing.md`：记录本页覆盖规范，并保留历史设计说明。
- `web/tests/weighing-backend-smoke.mjs`：在现有真实 API／Agent mock 回归中增加视角切换、放大与 Escape、资料大弹窗录入／查看、缺项聚焦、关闭重开草稿保留、嵌套资料选择、完成录入进入集中核对及五种屏宽无横向溢出检查。

原有鉴权、路由、权限、请求、轮询、业务校验、人工确认、吨制精度、提交未知恢复和抓拍绑定机制继续复用。入厂卸货和出厂装货语义沿用现有业务名称。

## 紧凑布局与资料弹窗修订

根据用户截图反馈，将桌面工作台外边距、面板间距缩至 8px，压缩顶栏与面板内边距；抓拍的视角按钮和元信息合并为同一列，避免窄列文字撑高面板。

取消页面底部常驻表单。车辆区以简短摘要及“录入运输资料／查看运输资料”作为入口，复用原有内容呈现在最大 1200px 的大弹窗中。全部补充字段及资料维护入口保留，已有运输保持只读。关闭自动保留草稿；采集后缺资料时弹窗聚焦缺失字段，完成录入可进入原有集中核对，不跳过正式确认。正文可滚动，底部操作固定可见，支持键盘关闭及焦点返回。

## 铺满视口与状态辨识修订

桌面工作台使用弹性布局铺满顶栏和提示栏下方的剩余高度，现场图片保持 `object-fit: contain`，重量仪表随区域扩展；较矮窗口或较长异常内容仍自然滚动，不截断操作。作业阶段（首磅／回磅等）及运输方向从查找按钮旁移至独立高对比大字状态行。车牌按省份加七位后缀定宽展示，保留普通、新能源、完整车牌粘贴及现有校验，窄屏按空间缩小字符格。

浏览器回归增加桌面区域铺满高度、状态行独占一行、车牌宽度不随面板扩展及新能源七位后缀无横向滚动检查。 本次因默认测试端口同时用于另一项验证，使用相同浏览器脚本的临时副本，将端口改为 API 18185／Web 4285／mock 18190，隔离执行；临时脚本在完成后删除。

## 验证

- `npm --prefix web run test:weighing:backend`：真实临时 SQLite／API／Vite／Agent mock 浏览器验证，覆盖服务端持久化、两方向首磅与回磅、先采集后补资料、识别候选与人工修正、抓拍核对、原始异常恢复、纠错／重称／作废重开、CSV、打印反馈和真实账号接管；新增工业 UI 检查通过。
- 布局检查：1920×1080、1366×768、1024×768、768×1024、390×844，无页面横向溢出，运输表单仅在大弹窗中展示，弹窗边界适配视口，1366×768 采集操作首屏可见。
- 本机截图产物：`.task/industrial-workbench-desktop.png`、`.task/industrial-workbench-mobile.png`、`.task/industrial-workbench-business-dialog.png`（忽略的本机验收产物，不纳入源码）。

浏览器检查使用隔离临时数据，脚本有超时并在结束时关闭浏览器、终止临时服务、删除临时数据库；不修改开发数据库。

## 真实设备待验收

当前现场图和采集证据来自既有 Agent 图片接口，实时视频流尚未接入；新增 UI 不宣称已实现实时视频。独立 Agent mock 验证不能替代真实 D12 仪表、摄像头／识别、网络断连及恢复、现场抓拍和物理打印联调。仍需使用真实设备核对重量时效、稳定状态、前后图片及识别候选与现场车辆的一致性。
