# 本厂初始化与 Agent 连接配置分离

> 2026-10-24 部分替代：[ADR 0030](../../adr/0030-local-device-responsibilities-and-configuration.md) 将 Agent 改为只填 Server 地址接入，不再生成配对文件、密钥或换机重绑；本厂入口收拢至配置管理。取消人员数量门槛、初始化两名称及连接地址不属于厂区资料继续有效。本页旧配对实现／验证是既有事实，新目标代码待实施。

2026-10-24，用户确认取消“至少两名实名操作员才能首次启用业务”的门槛，并将“本厂 Server 地址”移出本厂资料与首次配置，归入设备配对／连接设置。本决策替代 ADR 0028 中的操作员人数启用条件和首次配置必须提供 `serverUrl` 的条款，其余单一本厂身份、编号和授权边界继续有效。代码与软件验证已完成，实施状态和未完成的现场验收见[补充规格](../requirements/local-initialization-simplification-spec.md)。

两人门槛来自中心掌握密码、离线无法重置的旧方案；当前账号和密码已由本厂管理，人员备班应由厂方安排。本厂身份及地磅绑定保存成功即完成初始化；实际能否称重取决于当前账号权限、操作范围、设备状态及既有业务校验。操作员姓名和实际操作人追溯保留，不增加身份核验，也不按账号数量限制启用。

Agent 需要从自身主机访问的业务服务地址，但这个地址不属于厂区业务资料，也不是 Server 的监听配置。首次配对显式提供连接地址，后续以 Agent 保存并实际使用的连接配置为准，不保留厂区资料与设备配置两套可编辑来源。地址变更继续显式应用并核对生效，不以页面保存成功推断设备已重连；不引入自动发现。Agent 离线时通过设备主机配置和配对工具处理，不新增远程离线配对服务。
