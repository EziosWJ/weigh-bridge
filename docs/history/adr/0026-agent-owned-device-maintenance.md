# Agent 拥有设备配置，API 经现有通道维护

> 2026-10-24 部分替代：[ADR 0030](../../adr/0030-local-device-responsibilities-and-configuration.md) 将 Agent 配置归属收窄为串口与打印，相机／识别／视频服务归 Server；取消配对密钥及用户草稿，使用一次保存并应用，增加成功参数备份。主进程常驻、分机部署、系统级离线恢复及业务保护仍保留。新方案只有规格，代码待实施。

2026-10-23，用户接受并授权实施。设备配置文件、草稿、生效配置、回退及设备执行由现场 Agent 管理；业务 API 通过现有 WebSocket 通道转发维护请求并保留已有权限、厂区归属和业务审计，不再依赖 API 主机上的设备文件、CUPS 或 Agent systemd 服务。API／数据库与 Agent 可在同厂局域网内分开设备部署，同机仍是可选部署。

Agent 主进程常驻，页面启停的是设备执行和连接，应用配置在 Agent 内重载设备；整个进程的开机启动及故障恢复由 Agent 主机 systemd 负责。Agent 整个进程离线时，API 显示离线，无法读写实际配置或启动该进程；不增加远程启动服务，不自动排队重放维护操作。

设备身份及业务归属仍由业务服务管理，设备参数由 Agent 持有。保存草稿与实际生效分别反馈，配置应用和设备重启与采集、确认及打印执行协调；未确认旧采样在配置切换后需重新采集，已提交业务和打印账本保留。浏览器继续直接连接 MediaMTX WHEP，不增加媒体鉴权。

本决策替代 [ADR 0023](0023-standalone-site-baseline.md) 的强制同机部署及“设备进程停止仍由 API 直接启动”的约束，并调整 [ADR 0025](0025-camera-stream-maintenance.md) 的配置文件维护主体；本厂自治、三个核心服务、业务证据及已有权限规则保持。此前同机维护代码和验证属于过渡实现，完成情况见当前交付记录。
