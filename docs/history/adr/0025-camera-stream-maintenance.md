# 摄像头共享配置与本厂视频接入

> 2026-10-24 部分替代：[ADR 0030](../../adr/0030-local-device-responsibilities-and-configuration.md) 将可变数量相机、源凭据、直连 RTSP 抓拍及 MediaMTX 管理接口接入迁到 Server。MediaMTX 自由部署，WHEP 仅预览；“前后两路／源配置只由部署文件维护／不用 Control API”不再是新目标。代码和验证待实施，下文保留原决策与实现历史。

2026-10-23，已确认。正式现场以本厂 MediaMTX 作为视频配套服务：浏览器通过 WebRTC/WHEP 实时监看，Agent 继续通过 RTSP 取得当次抓拍。统一的是维护入口、流名称及配置生效版本，不要求两种用途使用同一协议；实时画面不构成正式称重证据。

设备维护保存 RTSP／WHEP 服务入口及前后流名称，沿用草稿、应用、核实和回退流程。应用期间暂停新的采集／确认并等待在途处理完成，成功后未确认的旧采集结果需重新采集。旧直连配置在明确切换前保留。系统不接管 MediaMTX 上游摄像头地址维护或自动重启，部署配置负责其接入和恢复。

按用户最终修订，MediaMTX 仅负责局域网转流，浏览器直接读取 WHEP，Agent 直接读取 RTSP；不增加播放令牌、HTTP 鉴权回调、Control API 或撤权断流机制。摄像头配置读取与维护操作沿用系统已有登录、业务查询权限和维护权限；摄像头原始参数在部署配置中维护。

这是对 [ADR 0023](0023-standalone-site-baseline.md) 配套部署范围的补充，两个自研进程与 PostgreSQL 的核心职责不变。软件实施、模拟验证与现场验收见[接入和交付说明](../../device/camera-live-preview.md)；本决策不代表真实摄像头或长时间运行已验收。

> 2026-10-23 维护主体与部署边界修订：见 [ADR 0026](0026-agent-owned-device-maintenance.md)。Agent 管理设备配置及设备执行，API 通过现有通道维护；支持本厂局域网分机，Agent 主进程离线由宿主机恢复。
