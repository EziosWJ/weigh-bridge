# 操作员业务修订前端模拟交付

日期：2026-10-18。依据：[补充 Spec](operator-weighing-corrections-spec.md)、[客户结论](customer-confirmation-checklist.md)、ADR [0013](../../adr/0013-formal-weighing-evidence.md)／[0014](../../adr/0014-manual-weight-adjustment.md)。本轮在已有未提交的独立工作台等改动上增量实施，保留原工作区；没有提交、推送、部署或修改远程 Issue。

## 已实现范围

- 操作员直接办理业务纠错、任务终止、单磅重称、作废关联重开、打印核实、补打和导出。复用称重模拟命令和页面，不增加申请或审批状态；系统账号、登录、JWT、真实 RBAC 与后端未改动。保留兼容的主管演示角色，管理员演示岗位仍维护资料。
- 隔日回磅沿用原任务、首次重量及抓拍，正常人工核对后续称，不要求核实说明。记录两次采集／确认实际时间、操作人和隔日续称关联。历史明确标记的运输疑点仍由操作员核实，无主管专办。
- 最终毛皮重支持双向人工调整，超原始值分别提示后可提交；差额为原始值减最终值，负数明确标注上调。净重自动计算，保留有限正数、0.001 吨精度及毛重大于皮重校验。备注选填，未填或清空保存“磅精度调整”，自填原样保留；未调整不补造调整备注。作废／重开／重称等操作原因继续单独必填。
- 作废后在原任务选择首次／二次及毛皮语义进行单磅重称，核对装载状态、沿用另一磅有效、新模拟抓拍后追加记录，记录替代目标及沿用另一磅的编号。未出单已有首磅仍可重称；任务不退回首磅，不重新走整趟流程。另一磅未确认有效或目标装载状态不符时阻止办理。
- 无法重采时可在关联重开内人工调整最终值，不产生采集记录。新单使用任务当前有效称重依据，并保存原始／上版最终／本版最终、人工来源、差额及人员时间快照；原单重量、图片、调整快照和预览保持原版，仅增加作废及关联操作历史。
- 同任务最多一张有效单；重称按采集编号去重，重开沿用已成功的关联单。重称与重开均复用模拟提交成功／失败／结果不明及查询恢复；失败不创建有效新单，查询后成功沿用原结果、失败继续办理。更正表单在提交时校验开始核对的依据，跨标签修改后须重新核对。
- 原始列表每任务一行，实际重称更新当前有效组合，二次时间只随二次重称变化；仅人工调整不改原始记录或日期。最终列表保留每版单据，两种汇总分别计算原始／最终净重，排除作废且不重复计重。CSV 保留符号、人工来源、备注、前后值、依据／替代关系和操作记录；打印预览使用对应版本最终重量及当时图片。
- 保留 v1／v2／v3 浏览器历史及既有 kg 来源；兼容字段增量增加，未清库。旧记录不补造备注、操作人、图片或时间，历史缺失明确显示未记录。继续使用原存储键及同源标签串行保存与同步机制。

## 实际限制与未实现

全部仍是浏览器模拟重量、静态模拟图片、浏览器存储和测试单据，装载状态由操作员勾选核实，系统没有真实传感器判断能力。未接入真实设备、车牌识别、现场 Agent／WSS、业务 API／业务表、正式电子过磅单或物理打印。结果不明和占用只是既有前端演示机制，同源标签协作不等于服务端业务锁或多终端事务保证。

普通刷新恢复任务、各版单据和历史，当前临时采集仍按既有规则失效并重新采集。浏览器存储失败会提示进度只在内存；历史缺失不反填。旧缓存中已经保存的主管身份、旧备注及旧动作名称如实保留。

隔日统计归属的最终业务口径、特殊运输方式、单据必填／打印字段及联数、客户导出模板等仍待客户答复；当前沿用既有日期筛选及 CSV。没有把这些待确认项目扩成新规则。正式业务按后续已授权阶段实现。
