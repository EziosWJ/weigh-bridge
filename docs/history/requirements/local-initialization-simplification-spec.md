# 本厂初始化简化与 Agent 连接地址归位

日期：2026-10-24。状态：用户已确认；代码与本次验收相关软件验证已完成，一项既有后端浏览器冒烟仍有时序失败（见实施状态），现场验收待完成。依据：[ADR 0029](../adr/0029-local-initialization-and-agent-connection.md)。本补充覆盖当前总规格中操作员人数门槛及 `serverUrl` 的相关旧要求。

## 本厂初始化与人员授权

- 本厂身份、地磅和 Agent 绑定在同一事务中首次保存成功，即初始化完成。不统计操作员人数，不要求先创建两个非内置账号，也不以姓名字段是否非空作为全厂启用条件。
- 保留一次性初始化、身份和编号锁定、并发保护、事务回滚及无需重启；未配置时允许登录管理，正式业务写入仍须拒绝。
- 保留 `local-status` 的 `{siteId, configured, initialized}` 和 capabilities 既有字段；`configured` 与 `initialized` 均表达本厂配置是否完成，不再表示人员或设备就绪。状态读取不应统计用户或写入启用标记。
- 已完成配置但旧 `initialized=0` 的现有本厂，应在升级后直接按已初始化处理，无需重新配置、补账号或重建数据库。可保留旧列作兼容，但不得继续用其旧值阻止业务；若改数据库结构或数据，新增 Goose migration，不改历史文件。
- 删除“两名实名操作员”提示；本厂页使用“配置状态：已配置／未配置”，不暗示设备可用。初始化按钮与成功提示保持清晰，不引入人员准备向导。
- 谁能称重继续由当前账号的 JWT、RBAC、启用状态和本厂查询／操作范围决定。不因为取消人数门槛而自动授予管理员或其他用户称重权限；已有具备权限和操作范围的账号可按正常校验办理。保留操作员姓名及实际操作人审计、单据追溯。

## Agent 连接地址

- 本厂详情、编辑和首次配置表单移除“本厂 Server 地址”。首次初始化不再要求 `serverUrl`。保留既有 API 路由和其他响应字段；兼容保留的 `serverUrl` 字段不得成为新的配置入口或运行依据，旧调用携带该字段时明确按兼容字段忽略，不覆盖 Agent 地址。
- 业务服务自己的监听地址仍由服务配置决定。本改动不改变监听端口、浏览器 API 基址或反向代理配置。
- 首次配对通过现有 `agent-provision` 工具增加显式地址输入（例如 `--server-url`），以操作员提供的、Agent 主机可访问的地址写入 Agent 连接配置。首次生成必须提供有效地址；更新已有文件未提供地址时保留已有有效地址，显式提供时才替换。不得回退读取 `wb_site.server_url` 或全局 `AgentSetting.server_url`，不得猜测浏览器 origin。
- 同机可用 `http://127.0.0.1:8900`；分机必须使用 Server 的局域网 IP 或域名，端口以实际部署为准。界面使用“Agent 连接的业务服务地址”或同等明确文案，说明地址从 Agent 主机视角解释。
- 后续连接地址以 Agent 配置为唯一有效来源。沿用现有设备维护连接区域与草稿／应用机制；实际允许编辑的字段以现有协议能力为准，不为本次任务强行扩展远程连接切换。若现有连接身份为只读，则展示实际地址并说明通过配对工具修改及显式重启／应用。整个 Agent 离线时不依赖网页完成首次配对。
- 地址修改不自动重连，不自动重放称重或打印。重新配对保留串口、摄像头、打印参数、维护草稿、未知配置行和完整打印账本；已有文件仍要求 `--update-connection`，保留受限权限、原子写入及敏感信息不输出。
- 兼容保留的数据库地址字段可暂不删列，但不再读取或更新为业务资料；排查导出接口、配对工具、安装／发布脚本和 mock 入口，避免残留对厂区地址的依赖。需要地址的旧导出接口应从请求显式获得地址或对缺少地址返回清晰错误，不静默生成带旧地址的连接配置，也不移除既有鉴权。

## 验收与回归

1. 空库启动可登录管理；无厂区时正式业务写入被拒绝。首次配置不填 `serverUrl` 成功，配置状态立即完成；重复与并发初始化仍受保护，失败事务不留下部分身份。
2. 仅一名有称重权限和本厂操作范围的账号，可在满足设备与业务条件时完成正式业务；没有第二个账号不再阻塞。无权限、无操作范围、停用账号继续拒绝。
3. 已配置而旧 `initialized=0` 的库升级后正常使用，厂区编号、业务记录、授权及设备配置不重置；读取状态不再按人员变化产生写入。
4. 本厂页面没有 Server 地址和两人提示；未配置、已配置、加载失败、只读及 390px 窄屏状态正常。设备配置状态不被混称为本厂初始化状态。
5. 配对测试覆盖首次地址缺失／无效拒绝、有效地址写入、更新保留地址、显式更新地址，以及不再读取旧数据库地址。验证设备参数、草稿、未知行和打印账本保护；测试使用临时目录和隔离数据库。
6. 同机／分机地址含义在帮助与部署文档一致；检查旧导出及安装／发布冒烟，保证无厂区地址也能完成配对链路。软件或 mock 验证不替代真实分机及设备验收。

按实际改动执行 `task backend:check`、`task frontend:lint`、`task frontend:build`；数据库相关行为执行 `task db:check`，数据库测试使用隔离临时 PostgreSQL。补跑受影响的本厂配置页面、单人称重闭环、配对及安装／发布冒烟；不以删除权限回归或跳过配置检查处理失败。交付记录追加真实结果与限制，不将旧两人流程通过结果改写为本次已验证。
