# Issue #2 独立称重工作台与模拟车牌识别交付

日期：2026-10-18。对应 [EziosWJ/weigh-bridge Issue #2](https://github.com/EziosWJ/weigh-bridge/issues/2) 及 [已确认规格](standalone-workbench-plate-recognition-spec.md)。本轮接续并保留工作区既有称重台减负、集中核对、摄像头尺寸及重量修订。

## 已实现范围

- `/weighing/workbench` 使用受原 RequireAuth 保护的独立外壳，无后台侧栏、公告、面包屑和通用顶栏。紧凑栏显示登录身份、演示岗位、模拟连接、后台／设置及全屏操作；原地址与任务参数继续有效。后台首页落在运输任务，登录后的原任务定位参数保留。
- 后台菜单、菜单搜索、任务与返回作业链接复用同一命名工作台窗口；关闭后可重开，阻止弹窗时显示直接打开入口。任务入口可将同任务首磅成功页带回继续办理状态。完整查询、资料和演示设置在后台标签打开；打印预览独立打开，工作台持续保留。
- 普通／新能源专用车牌控件覆盖工作台及主管纠错、关联更正重开，支持省份网格、后续字符分格、连续输入、整牌粘贴及自动大写；查找和业务更正时校验格式。查询仍允许部分车牌和任务／单号自由输入。旧特殊测试值可保持原值，未重写旧缓存。
- 模拟到磅展示识别过程、正确／错误候选或失败，候选明确待人工核对。现场图组合清晰的模拟车牌特写，并说明非照片原牌；识别不自动定位、采集或提交。编辑、定位或称重期间的新结果只提示，下一辆显式重置车辆边界。
- 后台演示设置提供普通与新能源即用示例，可设置现场车牌、错误候选、正确／错误／失败场景。识别修正无需额外原因，已确认业务纠错仍沿用岗位、原因和历史。
- 每次抓拍保存本次现场车牌、原始候选、人工确认值、核对时间及模拟识别／人工录入来源；详情及图片放大可查。首磅、回磅分别留存，后续设置和主管更正不改原证据；历史缺项显示“未记录”。
- 复用先采集后补资料、一次集中核对、首次确认建任务、二次确认出测试单及最终重量调整。原始／最终重量、重称、作废／重开、未知提交、打印和补打规则延续。

## 标签协作与缓存

加载缓存只读，不回写或清除其他标签采集；本页刷新恢复草稿，但未确认采集仍须重取。保存通过同一业务命令入口，在支持 Web Locks 的同源浏览器串行读取最新保存状态后应用命令，避免旧后台快照覆盖新任务、单据或资料。

业务资料实时同步，工作台保留本页草稿、采集图片和时间；补资料只提交变化字段，避免连续录入互相覆盖。切换演示岗位实时限制操作，保留采集；重量、稳定状态、证据、识别／提交场景或当前任务实际变化则使旧依据失效并提示。当前任务车牌被更正后须重新定位。重置带独立标记，使其他标签丢弃旧工作区。

缓存继续使用原 key 与版本；新增字段可缺省，历史任务、单据、图片和旧 kg 来源数据保留，不把当前候选反填到旧记录。

## 当前边界

全部是同一浏览器的前端模拟，不包含真实 OCR、实时摄像头、现场 Agent、WSS、设备采集、物理打印、正式称重 API／业务表或正式电子过磅单。现有 JWT、RBAC 和服务端响应未修改；未新增依赖或执行数据库迁移。

跨标签串行保存使用浏览器 Web Locks；不支持该能力时逐次读取最新缓存再保存，不提供真正同时写入的互斥保证。本轮不实现跨设备协作、生产级占用或分布式会话。

## 车牌分格对齐修订

用户指出 Windows 页面字符与格线错位后，实测原字符中心偏左约 9.5px。车牌输入改为由统一格宽与字体实际 `1ch` 计算首字符居中偏移及后续步距，尾部保留偏移空间，避免新能源末位输入触发滚动；小于 390px 时同步收缩格宽。保留原输入、粘贴和省份选择行为。

使用实际工作台测量并截图复核，覆盖 Windows Consolas 粗体、112.5% 放大及 1366／390／360／320px 视口；字符中心偏差小于 1px，新能源完整号码不滚动、页面不横向溢出。修复截图：`/tmp/plate-aligned.png`、`/tmp/plate-energy-aligned.png`、`/tmp/plate-windows-112-percent.png`。
