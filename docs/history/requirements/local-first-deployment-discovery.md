## 已确认的现场条件与原则

- 两个厂区，每厂各一台地磅及独立现场设备；不稳定的是互联网。
- 每厂本地独立完成称重业务，Web、Server、PostgreSQL 数据库及 Agent 部署在该厂工控机上，现场链路不依赖互联网。Q15 已由用户明确指定同工控机部署；资源不足时需要现场整改，不自动改为独立 Server 主机方案。
- 正式称重继续要求操作员确认、设备依据、对应抓拍及本地 Server 校验。本地正式单据不等待中心再次确认。
- 本地服务及设备链路正常时，外网断开不阻塞正常办理；本地业务服务或设备链路异常仍按相应故障规则处理。
- 中心统一维护物料、往来主体，厂区使用已同步资料。有网时自动持续同步，断网恢复后补齐积压；不要求管理人员随时在线查看。
- 物料由中心预先建档；普通操作员默认具有独立的临时往来主体补录权限，覆盖供货方、收货方和承运方，不因此取得完整资料维护权限。中心人工确认转正式或关联已有主体，同名不自动合并；保留原单据快照及来源，通过关联统一查询汇总。有网或断网均可补录，首次待确认时在本厂可重复选用，不下发为其他厂可选档案；收到中心退回补充结果后禁止新任务选用，既有任务续办，补充再提交须待中心确认后恢复新选用。
- 业务记录由所属厂区负责，作废、更正、重开及打印记录的后续变化也须同步；中心跨厂查询显示各厂数据更新时间。
- 资料变化不改写已出单的历史快照。厂区收到停用更新后禁止新任务选用，已开始任务可沿用原依据正常回磅；不能任意换用另一项停用资料。
- 同步重复传输不能重复生成业务记录或单据，不能触发重新打印；保持打印结果未知时人工核实等既有规则。
- PostgreSQL 继续作为 V1.0 Server 部署基线；未因本地部署决定改用 SQLite。
- Q1～Q23 已逐轮确认，其中 Q15 由用户指定同工控机部署，其余接受建议；Q16 的单盘故障保护目标保留，具体方案按用户要求暂缓讨论。

架构取舍见 [ADR 0021](../adr/0021-local-weighing-authority-and-central-sync.md)。真实仪表与摄像头驱动仍未实现，本轮讨论不改变既有验收状态。

## 代码事实与既有决策

- 当前实现以单个业务数据库支持多厂区隔离，见 [ADR 0018](../adr/0018-site-business-isolation.md)；已支持按厂区绑定 Agent，见 [ADR 0020](../adr/0020-managed-agent-bindings-and-local-activation.md)。
- 当前业务编号使用数据库内按业务日期递增的序列；多套独立数据库不能直接沿用单库唯一性假设。独立部署后的业务身份与单号方案需要设计。
- 当前账号登录与会话依赖 Server 所连接的数据库；不能仅把页面放在本地就认为已经具备独立登录能力。
- 本人改密和管理员重置密码均在本库事务内更新密码、撤销该用户全部会话并留审计，尚无跨节点密码或撤权生效机制。
- 既有任务正常回磅沿用业务快照，资料停用不直接阻塞；更正重新解析资料时，原任务已用的停用资料可保留，但主体业务身份仍会校验。
- 当前资料维护共用 `weighing:master:write`，内置操作员角色不含此权限；临时主体补录需要独立权限设计，不能为此向操作员开放全部统一资料维护。
- 现有厂区停用要求无未完成任务、未决打印或在线 Agent，且不会自动踢出 Agent；中心面对离线厂区无法实时确认这些条件。
- 现场资源记录不足以证明部署要求已经满足：已记录 `fcc-com-01` 为 HP ProDesk 400 G2 Mini、Ubuntu 26.04.1 LTS，已运行打印 Agent、维护服务及 CUPS；没有 CPU／内存／磁盘容量与剩余空间、本地 PostgreSQL 安装状态的记录。本次未连接现场主机，不能据机型推断资源足够；部署前须现场核验。用户已决定部署在工控机，资源核验属于部署验证，不再作为是否选用独立 Server 主机的待决问题。
- 当前通信契约围绕 Server 与 Agent，尚无中心和厂区之间的业务同步契约。抓拍与数据库都属于需保存的业务依据。
- 当前 `task db:backup` 只支持 SQLite 数据库，完整性验证不等于称重全链路恢复；尚无 PostgreSQL、抓拍和 Agent 打印账本的联合备份恢复、定时异机备份或从中心副本恢复厂区的交付。Agent 账本使用打印尝试 ID 防重，数据库回退与账本恢复必须协调，不能清空账本解决冲突。
- 既有编号要求服务端生成、系统内唯一、允许不连续、作废不回收、补打沿用原号、重开新号；历史测试依据不能迁移成真实采集。旧浏览器演示库继续不导入、不删除；集中服务端库拆分为中心及厂区后的存量分配尚未设计。
- 既有“云端断网暂停正式确认”是旧架构规则。本轮确认的目标规则见 ADR 0021；在新方案实现前，不得宣称现有软件已经支持断外网正式办理。
