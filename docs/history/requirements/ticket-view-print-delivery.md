# 单据查看与五联针打交付记录

日期：2026-10-19。依据：[已确认需求](ticket-view-print-spec.md)。

## 本次实现

- 单据详情先显示车牌、方向、供收方、物料和最终重量；原始依据、调整、完整业务快照、关联及历史记录默认折叠。
- 出单结果区、单据详情和可选预览复用直接打印操作。打印通过原有服务端命令下发 Agent，不调用浏览器打印。核实未知结果、查询原请求及填写原因补打在短弹窗内办理。
- 服务端生成 `weighing-compact-v1` 精简纸单字段，详情／预览及 Agent 打印任务共用；网页和 mock 展示相同内容。保留完整任务、单据及称重依据，不改写业务数据。
- 空白五联针打纸按约 210 × 99 mm 展示，五联作为一次复写、一次打印尝试；纸单只显示已确认的精简字段和状态标记，补打注明次数。
- 按单据引用的首次／二次记录 ID 选取实际确认时间，避免用历史被替代记录或当前时间；历史缺失字段显示占位符。
- 增加 `weighing.ticket_title`／`APP_WEIGHING__TICKET_TITLE`，默认“酒厂过磅单”，部署前填写实际名称。未新增数据库结构或迁移，继续沿用原鉴权和权限。
- 浏览器回归发现异步操作结束后清理旧核对窗口存在覆盖快速打开的新窗口的时序风险；清理移到发起操作前，保留现有采集及人工确认流程。

## 验证

- `task frontend:lint`、`task frontend:build`：通过；完成末次改动后补跑。
- `task backend:check`：通过，包含 `go test ./...` 和 `go vet ./...`。首次沙箱执行被本地 TCP 监听限制阻止，允许本机监听后完成。
- 新增服务端行为测试覆盖两种运输方向、仅最终重量、吨制精度、跨日时间、选定依据、缺失历史字段、作废／旧测试及补打标记。
- `npm run test:weighing:backend`：完整 SQLite／真实浏览器／WSS Agent mock 回归通过。新增断言验证默认折叠证据、查看预览不新增打印尝试、纸单常规内容尺寸、无照片及原始调整字段、详情直接打印不跳预览、Agent 与 Web 字段一致、人工核实及补打次数标记。原有两方向称重、更正重开、未知提交恢复、非法原始重量、响应式及账号接管流程一并通过；首次运行在后续回磅弹窗出现时序失败，调整窗口清理顺序后整轮重跑通过。
- 检查服务和浏览器均由测试脚本在 finally 清理，设有 180 秒超时。`git diff --check` 通过。

## 实际限制

当前实现了软件操作、服务端精简内容及 Agent mock 展示／回执，尚未实现或验收真实针打驱动。实际纸宽及送纸孔、五联复写清晰度、打印字体、长字段排版、首张定位、连续走纸和裁切，仍需纸张与真实打印机联调。网页物理尺寸与 mock 回报成功不代表真实出纸成功。
