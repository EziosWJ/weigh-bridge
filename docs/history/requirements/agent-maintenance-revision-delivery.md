## 实现

- 打印 Agent 增加 `--env-file`，与维护服务共用 `agent.env` 解析、默认校准和参数校验。发布 unit 显式读取同一文件，不再传入固定 Server 参数；受维护字段不再受进程中旧环境值覆盖，混用文件与连接／队列 flags 会明确报错。保留独立排障启动的旧 flags 接口。
- 有效环境文件要求明确提供 Server／Agent／地磅／队列项，缺失、无效数字或格式错误均提示修正，不静默回退默认身份。维护服务启动、状态／配置查询及执行维护动作前重新核对有效文件；草稿、上一份配置和密码继续持久化，外部编辑文件不覆盖已经单独编辑的草稿。
- 打印进程在本地心跳中记录配置摘要，维护页展示运行配置与文件一致、不一致或未知。停止、反馈过期、旧版本无摘要或环境文件无效时保持未知。密钥不回显，配置差异只显示是否已设置或待替换。
- 维护入口默认 `0.0.0.0:18901` + HTTP；支持回环／私网地址与可选 TLS，证书与私钥须成对提供。本地密码、接口鉴权、请求来源检查与敏感信息脱敏沿用既有约束。
- 顶部菜单分为总览、打印与队列、设备、配置、记录，支持地址 hash、刷新后保持当前页面及会话恢复。页面及样式随 Go 二进制提供，断云可用。
- 打印页提供服务行操作、本机全部队列及状态、按队列筛选的未结束作业列表和逐项选择取消。已运行 Agent 的启动按钮、已启用目标队列的恢复按钮置为不可用，其他队列仅查看。
- 启动、重启、恢复、取消、应用／回退配置和校准打印使用页面弹窗。重启 CUPS 列出全部可读取队列，旧作业处置显示作业编号、队列与提交信息；执行后重新读取实际状态。保留原有作业快照复核、未知状态确认、失败恢复和禁止自动重提规则。
- 配置页使用输入校验、已有队列选择、已保存／待应用提示及脱敏差异表。打印配置明确应用并重启打印 Agent 后生效；维护服务独立运行，应用失败仍可排障与恢复。
- 维护访问地址区显示当前协议与访问地址。监听和 TLS 由启动参数管理；同一地址重启后周期刷新恢复读取，地址或协议变化需使用新地址重新打开并登录。没有新增维护服务网络参数在线编辑器。
- 仪表与摄像头分区显示未接入和暂无预览；实际配置、采集、实时重量、稳定状态和 RTSP 视频预览仍未实现，不提供无效表单或云端图片替代。
- 维护记录与日志保留独立查询区，记录筛选加入响应次序保护，避免旧查询覆盖新查询。已有维护密码、记录和打印尝试账本保持可读取。

## 验证

| 检查 | 结果与范围 |
| --- | --- |
| `GOCACHE="$PWD/.task/go-build" task backend:check` | 通过，全量 Go tests 与 vet；新增覆盖共享文件优先、混用参数拒绝、缺失身份拒绝、无效数字拒绝、重启及外部编辑同步、草稿保留、密钥脱敏、运行摘要过期／不一致、HTTP／TLS 校验和多队列状态 |
| `task frontend:lint`、`task frontend:build` | 通过，现有 React 管理端检查；维护页本身属于 Go 嵌入资源 |
| `task agent:maintenance:build`、`task agent:printer:build` | 通过，生成 `bin/weighbridge-agent-maintenance` 和 `bin/weighbridge-agent-printer` |
| `node --check` 检查维护页 JS 与浏览器脚本 | 通过 |
| 构建后运行 `node scripts/check-agent-maintenance.mjs`（等价于 smoke 任务脚本阶段） | 真实 Chromium 通过五个菜单、断云、只读／维护鉴权、Agent 停止、CUPS 未知恢复、全部队列影响确认、逐项取消、配置保留／应用、校准样张、维护记录筛选、过期状态、390 px 手机布局及设备空状态 |
| 同一浏览器脚本内启动真实打印二进制 | 通过：只连接临时本地维护 HTTP 地址（没有 Agent WebSocket 接口，无法接收业务打印），验证在陈旧进程环境下仍按共享文件启动，维护页与进程配置摘要一致，未新增打印提交 |
| 局域网访问 | 测试环境私有 IPv4 网卡下，通配绑定的 HTTP 打开及登录、可选自签 TLS 打开均通过；不等同于现场网段／防火墙验收 |

首次沙箱内运行浏览器脚本因临时端口监听 EPERM 受阻，允许隔离临时服务后通过；该限制没有通过删测或跳过鉴权规避。脚本通过临时 PATH 注入假 systemd／CUPS 命令、使用临时私有数据目录，结束后清理浏览器、打印进程、维护进程和临时目录。浏览器截图保存在忽略的 `.task/agent-maintenance-smoke.png`，用于页面检查。
