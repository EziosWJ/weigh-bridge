## 已确认的业务规则

1. 原始毛重、原始皮重只读且保留依据。操作员观察原始值，人工录入扣减后的最终毛重、最终皮重；两个最终值默认等于对应原值。
2. 系统计算毛重扣减量 = 原始毛重 − 最终毛重，皮重扣减量 = 原始皮重 − 最终皮重；两项扣减量只读。原始净重与最终净重分别由对应毛重减皮重得出，不可直接编辑。
3. 最终毛皮重均为有限正数，不大于对应原值；最终毛重大于最终皮重。空白、零、负数、无效数字、超过三位小数和超原值均阻止确认。最终值等于原值表示未扣减，显示 0 吨；仅扣皮可能使最终净重增加。
4. 全部业务重量统一使用吨，业务精度为 0.001 吨，包括采集、输入、列表、详情、抓拍元信息、扣减、汇总、CSV、预览及物料单位。展示最多保留三位小数，并省略末尾无效零：5.000 吨显示为 5 吨，5.250 吨显示为 5.25 吨。输入步长为 0.001 吨，最多录入三位小数。
5. 二次采集后，在现有核对汇总中录入最终重量，一次确认完成二次称重与出单。原因选填，操作人、时间、原始值、最终值、系统算得扣减及操作前后值保留。只计算与预览不形成已确认记录。
6. 出单后沿用主管作废、更正重开：输入新单最终重量，系统重新计算扣减；原单及其调整快照不覆盖。同任务最多一张有效单，原始／最终双列表及各自日期和汇总规则保留。

例如，原始毛重 30 吨、皮重 10 吨；人工填最终毛重 29.8 吨、皮重 9.9 吨，系统显示毛扣 0.2 吨、皮扣 0.1 吨、最终净重 19.9 吨。仅把皮重填为 9.9 吨时，最终净重为 20.1 吨。

## 页面改造前的数据与计算准备

这些准备与页面属于同一交付；仅替换单位标签会把历史 32000 kg 错误显示为 32000 吨。

- 类型与业务入口：调整 `types/weighing.ts`、`lib/weighing/weights.ts` 和 `engine.ts`，命令接收最终毛皮重，业务入口重新校验并反算扣减，不能仅信任表单计算结果。扣减继续作为只读追溯快照保留，字段命名可沿用兼容，但输入语义须明确。
- 计算精度：业务值以吨表达，计算时使用 0.001 吨整数刻度或等价十进制定点；以规范后的毛皮重计算净重、以原值和最终值计算扣减，以净重累计汇总。显示和 CSV 最多保留三位小数，省略末尾无效零，不降低存储精度。
- 单位边界：新模拟采集直接使用三位小数吨值。未来设备若输出 kg，采集边界除以 1000 后规范为三位小数；若含更细精度，业务值按十进制四舍五入到 0.001 吨，原报文、原单位和原精度独立保留为证据。该归一化覆盖先前“完全沿用仪表精度”的业务约定；现场分度值与量程仍需设备阶段核实。
- 缓存升级：在 `migration.ts`、`seed.ts` 与 `store/weighing-store.ts` 中显式区分旧 kg 缓存与新版本。旧重量除以 1000，覆盖模拟配置、采集、任务／单据称重记录、图片关联重量、最终值及调整快照的原始／前／后值和扣减；迁移成功后写入新版本，已升级数据不得再次除以 1000。新示例与物料均使用吨。
- 历史精度：旧 kg 小数换算可能超过吨制三位小数，必须保留迁移前原单位数值作为历史依据；业务毛皮重按统一规则规范，再计算业务净重与扣减，不独立舍入各派生字段造成不等式。若舍入后出现零重量或原始／最终相对关系异常，保留旧记录并明确提示需核对，不自动生成或重开单据，不篡改旧证据。
- 保存与恢复：刷新、重开和未知提交恢复均读取同一已确认结果；不清库、不伪造历史身份和调整时间。已有作废版本、任务关系、重称关系、打印状态和编号不因换单位改变。

### 2026-10-17 核对异常重量时的计算反馈修复

浏览器复现了原始毛重、皮重均为 5 吨时，录入最终毛重 4.5 吨、最终皮重 1 吨，两项扣减量仍显示“—”的问题。原因是扣减展示依赖整笔出单校验通过；原始净重为零时计算被一并阻断。

已将两项扣减展示改为按各自最终重量独立计算：上述输入显示毛重扣减 0.5 吨、皮重扣减 4 吨；空白、精度错误、非正数或超过对应原值的字段显示“—”，不影响另一项。原始净重必须大于零的出单规则保留；核对底栏显示无法出单原因、返回调整模拟重量及重新采集的指引，并加强确认按钮的禁用显示。

验证：`task frontend:lint`、`task frontend:build`、`npm run test:weighing`（25 项）、`npm run test:weighing:smoke` 通过。新增 `npm run test:weighing:invalid-original` 浏览器回归，覆盖截图输入、单项非法值、阻止异常出单，以及调整回磅模拟重量为 1.2 吨后重新采集、确认生成测试单（最终毛／皮／净重为 4.5／1／3.5 吨，原始称重仍为 5／1.2 吨）。本次仍仅为 Phase 2A 前端模拟。
