使用前提与边界

      
    
        
  1. 先在「摄像头管理」为某台摄像头启用上报，并填写与本模拟器完全一致的设备序列号；未绑定或停用的序列号会收到 HTTP 403。
    2. 
        
  2. Server 必须可达，且本机地址满足设备上报入口的可信网络／IP 限制（例如 WEIGHBRIDGE_CAMERA_EVENT_ALLOWED_IPS）。
    3. 
        
  3. 工作台取得操作权后再触发新识别，候选规则与人工核对沿用现有流程；模拟器不会直接写数据库或绕过业务接口。
    4. 
        
  4. 本期只模拟心跳与车牌识别，不提供 RTSP 视频或抓拍图片，也不绕过正式称重的设备、抓拍和人工确认要求。
    5. 
        
  5. 模拟结果不能代替真实摄像头的现场验收；真实设备报文大小、图像、昼夜识别和长期稳定性仍需现场核对。
