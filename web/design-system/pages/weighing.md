# 本厂称重页面覆盖规则

2026-10-30 按 Issue #14 更新车辆确认、工作台直接录入和采集后直达核对；2026-10-25 收敛。业务行为以[业务规格](../../../docs/requirements/weighing-business-spec.md)为准，设备及相机职责以[设备规格](../../../docs/requirements/local-device-maintenance-spec.md)为准；本页只维护页面组织、视觉和交互。原模拟阶段及逐轮设计存于[页面演进档案](../../../docs/history/ui/weighing-page-evolution.md)，验证结果见[当前状态](../../../docs/next.md)。

## 页面分工与 Pattern

| 页面 | Pattern 与职责 |
| --- | --- |
| 旧本厂称重 `/weighing/sites` | 页面退役，重定向待回磅任务；工作台入口在顶栏，设备操作在设备维护 |
| 待回磅任务 `/weighing/tasks` | Standard List，放在“单据查询”下，默认筛选待二次称重；清空筛选恢复待回磅，可切换状态追溯已完成／已终止任务；任务详情与业务操作保留 |
| 独立工作台 `/weighing/workbench` | Form / Detail 业务变体，仅办理当前车辆；不包含后台侧栏、公告、面包屑和通用顶栏 |
| 任务、原始称重、最终单据 | Standard List；独立 Detail 展示记录、证据与历史，短处置操作使用 FormDialog |
| 物料、往来主体、分类 | Standard List；资料长表单独立编辑，多联系人在主体表单分组，分类使用简单列表 |
| 单据预览 | 只读文档视图；核实与补打在短弹窗办理，打印行为见业务规格 |
| 过磅单标题配置 | `/system/config` 顶部表单，编辑标题、预览样张并保存；内部身份自动建立，不提供厂区／地磅名称表单 |
| 摄像头／Agent 维护 | 分别采用[摄像头覆盖规则](cameras.md)与[设备维护覆盖规则](agent-maintenance.md) |

本厂身份来自数据库，初始化状态不代表设备就绪；缺少或异常地磅绑定时提示核对配置，不猜测目标。资料与系统配置分组沿用各自权限，用户的本厂查询／操作授权不替代角色动作权限。加载、失败、未配置及只读状态分别显示，保存失败保留输入。

后台顶栏通知图标右侧提供“称重工作台”主按钮，按确认权限及本厂唯一启用地磅操作授权打开并复用独立窗口；设备离线不隐藏入口。窄屏保留有可访问名称的图标入口。侧栏移除“称重作业”分组和本厂称重，操作员仅展示单据查询、基础资料、日志管理、系统概览及独立称重工作台入口，菜单搜索使用同一过滤结果；管理员沿用现有导航。本厂称重页退役，旧地址转到待回磅任务。操作员无指定返回地址登录或访问首页时，在当前窗口核对本厂唯一启用且已授权地磅并进入工作台；失败提供原因、重试和后台查询入口，不自动选择其他地磅。其他用户默认进入系统概览，概览区域继续遵守原有权限。

## 独立工作台视觉

沿用 Form / Detail 变体、ContentCard、SectionTabs、PlateInput、资料选择和核对窗口，不建立新通用 Pattern，不修改后台主题。

- 工业现代局部主题：背景 `#06121B`、面板 `#102331`、边框 `#315065`；正文 `#EDF8FF`、辅助 `#AFC5D5`；读数 `#3CE0F5`、操作 `#168FE5`、正常 `#41D8A0`、警告 `#FFB454`。Portal 弹窗应用同一局部主题，离开工作台恢复后台主题。
- 中文使用本机微软雅黑／思源黑体，重量使用 Bahnschrift／DIN Alternate 与等宽数字；普通桌面读数 76px、大桌面 96px、手机 60px。阶段和毛／皮类型独占醒目状态行，顺序与类型分别推导。
- 顶栏显示本厂／地磅、当前账号、真实连接状态，以及后台、释放操作权、全屏入口。菜单及搜索复用命名窗口，路由更新保留当前地磅，不在办理中切换现场。
- 桌面左侧观察、预览与本次证据，右侧依次为车牌与“确认车辆”、首磅资料、状态与读数、当前操作；一次确认即完成车牌核对并定位首磅或回磅。首磅的运输方向、物料和供收方直接在车牌下方选择，补充运输信息折叠；已有任务只读展示原快照和首次依据，完整资料在大弹窗查看。面板间距及外边距 8px，工作区铺满顶栏下方剩余高度。
- 完整资料弹窗最大宽度 1200px，正文可滚动、底栏可见，只读呈现已有任务快照，纠错入口前往任务详情。首磅资料直接在工作台编辑，采集前后均可补齐且不清除有效采集；采集后缺必填项在核对窗口内明确列出并直接补选。
- 车牌区域以文字显示候选、相机来源、时间及待核对状态；候选以内联标签紧跟车牌输入排列，不挤占下方阶段、提示和操作区，同一相机只显示一次；多车牌显示冲突并允许选择，识别成功不自动查找、采集或确认。人工核对后一次点击“确认车辆”完成车牌确认并定位首磅或回磅，阶段与毛／皮类型独占醒目状态行。厂家推送图片不展示，使用既有实时画面及现场车辆核对。
- 既有品牌素材为 `public/weighbridge/brand/scale-mark.svg` 和 `backgrounds/industrial-grid.svg`。现场画面由真实输入或明确标记的模拟源提供，空态显示原因；无有效当前重量显示“—”，诊断零值显示 `0 吨`。

## 核对、失效与反馈

使用单一集中核对窗口同时展示车辆、业务、原始／最终重量和图片状态。最终明确确认才提交，关闭窗口不提交；双向调整、默认备注、单磅重称与版本行为统一引用业务规格。

核对窗口最大宽度 1180px：第一步顶部摘要显示车牌和本次重量，办理阶段及毛／皮类型由标题和重量标签表明；运输方向与其他业务资料以无卡片的多列字段紧凑排列，所填补充信息一并展示，未填写时不占空位。抓拍图片及名称、时间集中排列并支持放大，常见桌面尺寸尽量在首屏展示；图片状态和异常仍直接提示。业务核对及确认流程的辅助说明收在问号中，车辆完全上磅和现场核对提醒直接显示。回磅第二步将摘要压缩为一行，放大展示原始毛／皮重、调整前净重、净重调整量和调整后净重。调整规则及精度说明收在对应问号中，支持鼠标悬停、键盘聚焦与触屏；校验错误及上调警告直接显示。固定底栏保留失效或待加载原因和主操作；窄屏业务资料和图片依次排列，操作按钮占满宽度。原始异常或输入错误时净重显示待核对状态，底栏说明原因，避免重复提示。

采集成功后冻结重量、时间和图片并直接打开集中核对，不再要求额外点击“开始核对”；后续实时读数、稳定状态、Agent 连接及设备／抓拍配置变化不撤销结果，不设确认倒计时，关闭后重开也使用冻结重量并区分实时读数。资料不齐时在窗口内明确列出缺项并可直接补选，补齐后无须重采即可确认；允许重新采集。回磅同时显示首次依据、本次重量、预计净重（注明未出单）和最终重量调整。业务资料变更时保留原核对内容并提示返回重新核对；改车牌、主动废弃／重新采集及操作会话变化按业务规则处理。提交期间保留窗口、显示“正在保存…”并禁用关闭与重复提交；明确失败保留错误，结果未知转为待核实并先查询原请求。

查找、采集、确认、查询未知结果、接管与打印使用轻量 Toast 反馈成功／失败／待核实；字段与设备条件在页内说明并定位。重量区以醒目文字状态逐一显示设备离线／故障、等待有效上磅、未稳定、稳定可采集、采集中、已采集待确认、办理完成和提交待核实，并给出适用的原因和下一步；状态不只依靠颜色。实时读数与冻结采集重量分别标注，冻结值同时显示采集时间；离线或过期不以旧值冒充实时重量。抓拍失败、非强制无图按真实状态显示。人工修正车牌、新候选保护与后台资料协作见业务规格。

## 预览与证据

实时预览读取 Server 摄像头列表，用实际名称选择，保留三档大小与放大；完整呈现车辆，尺寸变化不改变采样。画面连接中、播放、冻结、重连、后台暂停、待同步及未配置分别表达；隐藏、离开或切换时清理连接，放大复用已有流，Escape 关闭并恢复焦点。

当次抓拍与实时画面分别展示。核对及历史按摄像头逐张显示当时名称、来源、时间及失败原因，旧 front／rear 历史按原视角读取；不以固定两图或 Agent 上传标签限制新证据。无强制抓拍且缺图时展示实际状态，不等待不存在的图片。预览失败不直接阻断 Server 直连抓拍。

工作台左下证据区采用“整行状态栏 + 抓拍内容区”：标题、冻结策略标签和取得图片数量同行，正常等待使用中性相机图标，不显示警告框；无车牌参考时不保留占位框。未采集时采用紧凑空态，采集后按实际摄像头数量并排显示缩略图、当时名称和时间，窄屏自动换行，多图区域内部滚动；每张图片独立放大并在关闭后恢复焦点。非强制无图、部分抓拍失败和图片加载失败分别表达，保留逐台原因；实时预览仅用于监看，图片随确认称重保存。

## 后台列表、票面与响应式

六个业务／资料列表沿用 Standard List。宽度至少 1024px 时按顶栏下方剩余高度布局，表头固定、表体纵向滚动、分页可见；宽表固定首列及末列操作，中间横向滚动，短分类表只固定表头。窄屏取消固定列、保留全部列及表内横向滚动，窗口过短时允许自然页面滚动。

正文保持 14px，长名称、地址、备注可换行，日期／时间分行且使用北京时间；筛选项完整保留，权限、未知结果及错误提示不隐藏。1366×768、1280×720、1024×768 与 390px 是既有布局核对尺寸。

票面按业务规格的精简快照呈现，黑白、宋体、表格外框及分隔线，设计尺寸为 241×93 mm（241×279 mm 穿孔纸三等分，含孔边）；175 mm 宽票面水平及垂直居中。标题只使用保存的配置值；完整单号独占一行，毛皮净重数值加大加粗，签字行至少 13 mm，两次称重时间保留完整日期。五联一次复写。窄屏只让纸单容器横向滚动，业务按钮保持可操作。查看与预览均不触发打印。

键盘焦点可见，弹窗支持焦点约束、Escape 与关闭还原；嵌套放大时正确移交焦点，尊重减少动态效果。前端检查及受影响浏览器入口见[开发指导](../../AGENTS.md)，具体通过范围只记录在交付证据中。
