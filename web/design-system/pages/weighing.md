# 本厂称重页面覆盖规则

业务行为以[业务规格](../../../docs/requirements/weighing-business-spec.md)为准，设备及相机职责以[设备规格](../../../docs/requirements/local-device-maintenance-spec.md)为准；本页只维护页面组织、视觉和交互。原模拟阶段及逐轮设计存于[页面演进档案](../../../docs/history/ui/weighing-page-evolution.md)，验证结果见[当前状态](../../../docs/next.md)。

## 页面分工与 Pattern

| 页面 | Pattern 与职责 |
| --- | --- |
| 旧本厂称重 `/weighing/sites` | 页面退役，重定向待回磅任务；工作台入口在顶栏，设备操作在设备维护 |
| 待回磅任务 `/weighing/tasks` | Standard List，放在“单据查询”下，默认筛选待二次称重；清空筛选恢复待回磅，可切换状态追溯已完成／已终止任务；任务详情与业务操作保留 |
| 独立工作台 `/weighing/workbench` | Form / Detail 业务变体，仅办理当前车辆；不包含后台侧栏、公告、面包屑和通用顶栏 |
| 任务、原始称重、最终单据 | Standard List；独立 Detail 展示记录、证据与历史，短处置操作使用 FormDialog |
| 物料、往来主体、分类 | Standard List；资料长表单独立编辑，多联系人在主体表单分组，分类使用简单列表 |
| 单据预览 | 只读文档视图；共享打印操作在票面外展开，打印行为见业务规格 |
| 过磅单标题配置 | `/system/config` 顶部表单，编辑标题、预览样张并保存；内部身份自动建立，不提供厂区／地磅名称表单 |
| 摄像头／Agent 维护 | 分别采用[摄像头覆盖规则](cameras.md)与[设备维护覆盖规则](agent-maintenance.md) |

本厂身份来自数据库，初始化状态不代表设备就绪；缺少或异常地磅绑定时提示核对配置，不猜测目标。资料与系统配置分组沿用各自权限，用户的本厂查询／操作授权不替代角色动作权限。加载、失败、未配置及只读状态分别显示，保存失败保留输入。

后台顶栏通知图标右侧提供“称重工作台”主按钮，按确认权限及本厂唯一启用地磅操作授权打开并复用独立窗口；设备离线不隐藏入口。窄屏保留有可访问名称的图标入口。侧栏移除“称重作业”分组和本厂称重，操作员仅展示单据查询、基础资料、日志管理、系统概览及独立称重工作台入口，菜单搜索使用同一过滤结果；管理员沿用现有导航。本厂称重页退役，旧地址转到待回磅任务。操作员无指定返回地址登录或访问首页时，在当前窗口核对本厂唯一启用且已授权地磅并进入工作台；失败提供原因、重试和后台查询入口，不自动选择其他地磅。其他用户默认进入系统概览，概览区域继续遵守原有权限。

## 独立工作台视觉

工作台采用柔和浅灰一体配色（方案 1），整页收敛在同一明亮舒适域并消除大面积黑白硬撞色。画布采用柔和雾灰底（`#E8EEF5`），左右主卡片采用柔白底（`#FCFDFE`）、`12px` 圆角、细边框（`#D6E0EB`）与细腻微阴影，主操作与状态沿用全站语义色。正文和车牌使用后台无衬线字体，工作台车牌输入为一体边框的蓝牌省份徽章配 21px 加粗号牌。双层嵌入式工业仪表盒保留精工结构并改为浅金属银灰渐变外框（`#E2E9F2 → #D5DFEB`，边框 `#C2CFDF`）与内凹浅雾蓝 LCD 读数屏（`#ECF1F7 → #F5F8FC`，边框 `#C3D0DF`），等宽读数使用 Bahnschrift／DIN Alternate，常规桌面 64px、大桌面 72px、矮屏 56px、窄屏 48px，有效读数整数深墨蓝（`#0F2942`）、小数与单位按状态呈精工深翠绿（`#0F766E`）／深海蓝（`#0369A1`）／沉稳琥珀（`#B45309`）／深红（`#B91C1C`）区分。无有效重量显示柔和中灰（`#94A3B8`）大号「—」，有效零值显示 `0 吨`。

- 柔和浅灰白顶栏（`#F7F9FC`、底边 `#D4DEE9`）在标准桌面高 52px，同行放置柔和浅蓝底（`#E6F0FF`）配深海蓝（`#1677FF`）秤图标、深灰粗体（`#1E293B`）工作台标题、厂区／地磅（`#475569`）、浅绿／浅琥珀 Agent 状态胶囊和当前账号。操作区统一使用清爽浅色描边按钮（白底、`#CBD5E1` 边、`#334155` 字，人工补单、过磅单、后台查询、释放操作权、全屏），异常接管保留醒目琥珀警告态，按权限和会话状态显示。后台查询复用命名窗口。
- 标准桌面（≥1100px）铺满顶栏下剩余视口，外边距与栏距 12px，左侧现场画面约占 57%，右侧作业台最小宽 400px。视频优先时两区纵排，作业台在画面下方。平板及手机纵向排列，页面可自然滚动。
- 作业台按嵌入式仪表盒、车辆与资料、称重操作三段排列。标准桌面仅中部滚动，仪表固定在顶部，操作贴底。仪表外框抬头行并列显示阶段标牌（未定位柔和冷灰胶囊，已定位沉稳深海蓝胶囊 `#1D4ED8`）与浅底语义状态胶囊（浅绿／浅琥珀／浅蓝／浅红），内凹屏显示读数与白底描边可重采按钮，外框底行标注最近上报或采集时间。
- 省份徽章（已选蓝牌实底、未选浅蓝描边）、车牌号输入组成一体车牌条并与「确认车辆」紧凑同行，空间不足时换行。候选以可选择的标签紧随输入，显示来源和时间，同一相机只显示一次。多个候选明确提示冲突，人工核对后一次确认定位首磅或回磅，确认按钮随之降为次级。缺省份时聚焦省份按钮。未定位车辆时，在车牌下方自然呈现「场内待回磅车辆」快速点选队列，仅展示与统计 24 小时内的有效待回磅任务（标题旁标明「24小时内」，超期任务不在工作台快捷队列展示，不影响后台列表与手工录入定位）；当摄像头推送或设备识别命中其中车辆时，对应行以左侧强调边条、浅蓝底色与「相机已识别」徽标高亮并置顶优先展示（常规展示前 5 条，命中超 5 条时全部可见），点选仅填入车牌并保留对应识别候选来源供人工核对，仍须点击「确认车辆」；若 24 小时内无待回磅任务则展示柔和浅灰底「称重作业流程」3 步紧凑指引与设备／抓拍就绪摘要，消除空闲留白。同车多张流转单显示已有的登记时间、合同号及司机，流转单和异常提示保留对应操作。操作员结合实时画面和现场车辆核对相机候选。
- 首磅在基本信息页签选择运输方向、物料和供收方，在补充信息页签填写选填资料。运输方向使用分段单选，物料和供收方在空间允许时并排。已有任务只读展示原快照，直接列出首次称重重量及时间、隔日状态和已有流转单号，并提供「查看完整资料」。有效采集期间仍可补齐资料。
- 底部白底操作区集中显示阻断原因、卸货确认、办理结果和待核实提示。全宽 44px 主按钮启用态带柔和主色投影、禁用态用柔和浅灰实底，随状态切换为采集重量、继续核对、查询上次提交结果或办理下一辆车，按原请求重试使用次级按钮。

## 临时往来主体登记

- 在可登记的角色字段标题旁常驻清楚的次级按钮，分别显示「＋ 登记临时供货方」「＋ 登记临时收货方」或「＋ 登记临时承运方」。
- 搜索成功但无结果时，结果区显示「未找到」及对应角色，并提供登记入口。将搜索词带入可编辑的名称。搜索失败时显示「重试搜索」。
- 登记弹窗按角色命名，首先展示名称和主体性质。「企业」「个人」并排，初始均未选中。当前身份随入口带入并固定，其他业务身份放在「同时用于」中。主操作使用「保存并选用」。发现同名时，优先显示可用档案的简称、地址、联系人和电话，并显示「正式／临时」和主体性质；编码放在次级行。操作员可选用已有档案或继续登记。主体性质使用浅色描边选项和浅蓝选中态，同名档案使用浅琥珀提示。
- 首磅核对窗口缺供收方时提供同样的搜索和登记入口。登记完成后回到核对窗口，自动填入本趟资料并继续使用冻结的重量和抓拍。
- 关联粮食流转单后，在供货方字段只读展示正式供货方名称和「来自粮食流转单」，编码可通过问号查阅。变更从流转单选择处处理。指定供货方尚未同步或已停用时显示具体原因。承运方继续提供选填入口。

## 核对、失效与反馈

工作台弹窗沿用浅色公共组件。正文支持纵向滚动，操作底栏可见，窄屏主操作保持可达。字号按六档组织，首磅依据、完成摘要和补单出单净重按各窗口的摘要密度收紧。

| 层级 | 字号／行高 | 字重 |
| --- | --- | --- |
| 弹窗标题 | 16px／24px | 600 |
| 分区标题 | 14px／20px | 600 |
| 字段标签 | 13px／18px | 400 |
| 常规业务值 | 15px／22px | 600 |
| 重点车牌 | 22px／28px | 700 |
| 重点重量 | 28–30px／34px | 700 |

- **集中核对（最大宽度 960px）**。第一步用浅灰摘要并列车牌和本次采集重量，阶段与毛／皮类型由标题和重量标签表明。细线分隔的业务明细桌面三列、窄屏两列，长值换行。回磅列出首次称重依据与预计净重，并注明未出单。缺项就地显示浅琥珀提示并提供补齐表单。抓拍跟随业务资料，显示数量、策略及异常，每张可放大。第二步以紧凑摘要展示车牌与业务上下文、已有的云端化验或接收依据，以及原始毛重、原始皮重和调整前净重。每条扣减并列原因、方式、输入、折算和删除按钮，窄栏换为两列，「其他」的补充说明独占一行。底部浅蓝算式突出出单净重，错误和待加载状态在固定底栏可见。规则说明支持悬停、聚焦和触屏。
- **查看运输资料（最大宽度 760px）**。顶部并列车牌与任务状态、首磅依据与时间。首磅重量为 24px，可附隔日或重称信息。基本信息和补充运输信息采用 15px 双列键值明细，底栏提供任务详情及异常处置入口和关闭按钮。
- **称重完成（最大宽度 520px）**。浅绿摘要突出 20px 车牌及 24px 首磅重量或最终净重，明细列出任务号、关联单号及称重或出单时间。回磅提供共享打印操作。底栏提供返回当前页面和开始办理下一辆，手机纵向排列。
- **人工补单（最大宽度 700px）**。基本资料分两列，桌面将首磅、回磅重量各自与实际时间同行配对，手机按顺序堆叠。方向决定毛／皮重标签。可展开扣减表单，选择补单原因，浅蓝摘要用 24px 显示最终净重。出单回执沿用浅绿成功摘要。
- **过磅单抽屉**。白底右侧抽屉宽度取视口的 92% 与 1280px 的较小值，1024px 及以下占满视口。浅灰筛选区提供业务筛选、日期区间和日期快捷项，列表区显示厂区与汇总。标准表格保持固定表头及支持尺寸下的固定首末列，窄屏横向滚动表格，分页仍可见。车牌、单号、有效性、打印状态和最终净重集中展示，可打开详情和有权限的预览。

成功采集即冻结重量、时间及抓拍并打开核对窗口。后续设备状态及配置变化、关窗重开、补齐资料均沿用冻结依据。业务资料变化时保留原核对内容并提示重新核对，改车牌、废弃重采及操作会话变化按业务规则处理。只有明确确认才提交。提交期间锁定关窗与重复提交，明确失败时保留错误，结果未知时先查原请求。

查找和采集失败在对应操作处显示。仪表区保留设备状态和采集时间，操作区显示阻断、完成或待核实状态。离线或过期时清除实时读数。共享打印区按状态提供「打印本单」「查看打印状态」「核实打印结果」，核对实际纸票后有权限的操作员可填写原因并确认补打。净重扣减、重量更正及单磅重称规则见[业务规格](../../../docs/requirements/weighing-business-spec.md)。

## 预览与证据

实时预览使用 Server 摄像头配置及实际名称。桌面提供「标准／视频优先」分段开关，主画面支持全屏，Escape 返回后恢复焦点。多路监控画面收进统一柔和浅钢灰画框（`#D5DFEB`、边框 `#C2CFDF`、`10px` 圆角、`4px` 内边距与格子间距，格子圆角 `7px`），单路铺满，两路主上辅下，三路主画面跨上排、两幅辅助画面并排在下；超过三路时通过选择器更换画面。选中已显示的辅助画面只改变网格位置，放大沿用现有流。连接中、播放、冻结、重连、后台暂停、待同步及未配置各有明确状态；断开／重连／连接中／未配置占位统一使用柔和冷雾灰底（`#E5ECF4`）与浅色磨砂胶囊（`rgba(255, 255, 255, 0.88)`、边框 `#CBD5E1`、深灰字 `#334155`）；正在播放实时视频（`data-camera-state="live"`）底板为中性深石板灰（`#1E293B`），状态胶囊与全屏／放大画面按钮切换为深色半透明磨砂胶囊（`rgba(15, 23, 42, 0.72)`、白字）。隐藏、离开或移除画面时清理对应连接。

当次抓拍位于现场画面下方。等待采集时用紧凑状态条显示标题、抓拍策略及状态，有参考车牌时一并显示。取得证据后按实际摄像头数量排布缩略图，显示当时名称与时间，图多时在区域内滚动。核对弹窗中的抓拍桌面最多三列，两张并排，单张居中，缩略图高 150px；手机单列，可滚动正文查看。放大使用浅色预览，关闭后恢复焦点。

实时预览用于监看，正式称重证据来自当次抓拍。抓拍失败、非强制无图及图片加载失败分别显示，逐台保留失败原因；历史记录按当时的摄像头名称、来源、时间及图片追溯，旧 front／rear 仍按原视角读取。Server 直连抓拍独立于实时预览状态。

## 后台列表、票面与响应式

六个业务／资料列表沿用 Standard List。宽度至少 1024px 时按顶栏下方剩余高度布局，表头固定、表体纵向滚动、分页可见；宽表固定首列及末列操作，中间横向滚动，短分类表只固定表头。窄屏取消固定列、保留全部列及表内横向滚动，窗口过短时允许自然页面滚动。

正文保持 14px，长名称、地址、备注可换行，日期／时间分行且使用北京时间；筛选项完整保留，权限、未知结果及错误提示不隐藏。1366×768、1280×720、1024×768 与 390px 是既有布局核对尺寸。

票面按业务规格的精简快照呈现，黑白、宋体、表格外框及分隔线，设计尺寸为 241×93 mm（241×279 mm 穿孔纸三等分，含孔边）；175 mm 宽票面水平及垂直居中。标题只使用保存的配置值；完整单号独占一行，毛皮净重数值加大加粗，签字行至少 13 mm，两次称重时间保留完整日期。五联一次复写。窄屏只让纸单容器横向滚动，业务按钮保持可操作。查看与预览均不触发打印。

键盘焦点可见，弹窗支持焦点约束、Escape 与关闭还原；嵌套放大时正确移交焦点，尊重减少动态效果。前端检查及受影响浏览器入口见[开发指导](../../AGENTS.md)，具体通过范围只记录在交付证据中。
