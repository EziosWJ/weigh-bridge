# Phase 2A 称重页面覆盖说明

当前改版依据：[可用性需求](../../../docs/requirements/phase-2a-usability.md)。沿用现有 Pattern 与组件。

- 工作台：Standard Form + Detail 变体，仅当前车辆车牌定位、业务核对、重量确认、结果与下一辆车。首次一次确认建立任务；回磅展示首次依据。演示配置移至独立设置页。
- 任务／单据列表：Standard List，只筛选、查找、导出及进入详情，使用既有列表骨架。
- 任务／单据详情：独立 Detail Page，ContentCard + DetailItem 展示依据和历史；主管短操作使用 FormDialog。
- 打印预览：独立只读 Detail Page，清楚显示测试标记、原单号与补打状态；模拟打印是单独动作，无物理打印。
- 物料／往来主体：独立 Standard List 与编辑页面；多联系人属于主体表单分组，分类采用轻量独立列表。
- 演示设置：独立 Standard Form 页面集中模拟条件、岗位、占用接管与模块重置。

侧栏提供业务分组，不在每个页面重复模块导航。默认进入工作台；开发示例集中且默认折叠。页面仅保留简明测试与设备未接入提示。保留中性、专业、高密度风格和窄屏列表横向滚动，不新建通用页面框架。

## 工作台紧凑作业变体

工作台沿用 Form / Detail 的业务变体，压缩顶部为车牌栏；不以自由切换的Tab组织顺序流程。首磅只常驻必要信息，补充运输信息用原生details默认收起、显示摘要；详情处置表单保持原完整字段。

桌面左右分区：左侧必要业务信息／回磅依据，右侧为重量和当前操作，使用sticky保持位置。常规1366×768视口需计入240px侧栏及64px顶栏后核对首屏；窄屏正常堆叠，不使用固定高度截断内容。异常及未知提交替换当前操作内容，不挤到新的长提示区。测试标记、人工确认和资料辨认信息始终保留。

## 逐项人工核对

采集后主操作打开既有 Dialog 组成的核对交互，四步依次显示本次实际值；核对进度、上一项、不一致返回与最终汇总明确区分。各步仅记录本次局部核对进度，最终按钮才提交测试称重。核对内容变化立即结束旧会话，不把进度缓存为已确认业务状态。键盘焦点随步骤进入标题，弹窗支持关闭、焦点约束和关闭后还原。

## 模拟摄像头与抓拍

工作台左侧使用紧凑摄像头图片卡，与业务信息并排；桌面右侧重量及确认区继续固定。当前预览为静态内置示例，采集重量同步生成图片快照，不增加单独抓拍步骤。逐项核对第四步展示本次图片、关联手填车牌、采集时间和重量，图片加载后才能继续；点击缩略图使用既有 DetailDialog 放大。任务、单据详情保留逐条原始图片，打印预览展示当前首／回磅图；旧历史无图明确留空。图片放大期间暂停外层弹窗焦点约束与 Escape，关闭后恢复。所有图片标记模拟，示例画面不代表当前车辆或实时视频。

## 人工扣减与双列表

依据：[人工重量调整需求](../../../docs/requirements/manual-weight-adjustment.md)。二次称重逐项核对的最终汇总内只读展示原始重量、填写最终毛皮重及选填原因，由系统反算只读扣减量与最终净重；同一次确认出单，不增加任务状态。弹窗底部固定显示最终毛皮净重及确认按钮，内容区可独立滚动。

原始称重和最终单据为两份独立 Standard List 页面，分别按任务／单据为行，分别使用二次确认／出单日期；单据列表沿用原有路由，新增原始列表入口。详情展示扣减快照和前后值，纸质预览仅显示最终重量；预览中的模拟抓拍也隐藏关联的原始重量。

## 最终重量录入与吨制修订（已完成）

所有业务重量使用吨，精确至 0.001 吨；显示最多三位小数并省略末尾无效零，例如 5.000 吨显示为 5 吨。最终毛皮重默认带入对应原值，可手动下调。核对汇总与更正重开复用同一输入区域，扣减量仅由系统计算。列表、详情、抓拍元信息、预览、CSV、汇总、物料单位和演示重量均已同步。保留既有页面 Pattern、四步核对和固定确认区；旧 kg 缓存由数据迁移统一换算并保留来源值，详见 [交付记录](../../../docs/requirements/weight-entry-tonne-plan.md)。
