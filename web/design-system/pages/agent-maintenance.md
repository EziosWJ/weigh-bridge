# 设备维护页面覆盖规则

适用 `/system/agent-maintenance`，采用 Detail、Standard Form 与 Standard List 组合变体，沿用 MASTER 后台规范。职责及失败规则见[设备规格](../../../docs/requirements/local-device-maintenance-spec.md)，相机、识别及视频设置使用[独立摄像头页](cameras.md)。旧页面说明存于[演进档案](../../../docs/history/ui/agent-maintenance-page-evolution.md)，实际验证见[当前状态](../../../docs/next.md)。

## 视觉与布局

沿用背景 `#F5F7FA`、面板 `#FFFFFF`、边框 `#E5E7EB`、正文 `#1F2937`、辅助 `#6B7280`、操作 `#1677FF` 对应 token；状态色表达实际状态。正文 14px、卡片标题 16px，重量和时间用等宽数字，内容左对齐。

页面按“标题与刷新 → 最近检查时间 → 五个业务页签 → 当前内容”组织。SectionTabs 支持方向键、Home／End 和可见焦点。总览用紧凑服务状态条和设备执行控制；“打印机管理”组合打印诊断、未结束打印作业、队列状态、维护操作与打印校准配置；“仪表管理”组合重量、串口状态与仪表配置。两页均按状态和配置桌面并排、窄屏堆叠，生效摘要和手动备份管理集中在独立“配置备份”页，用 DataTableCard／TableToolbar／Pagination 展示列表，FormDialog 创建及恢复，DetailDialog 查看完整参数对比。记录使用 DataTableCard／TableToolbar，表格局部横向滚动；日志使用保留换行的独立滚动文本区。

## 参数与结果

- FormSection、Field、Input、Select 只承载串口、波特率、Agent CUPS 队列、单据节长、水平／垂直偏移、缩放及高级宽度。业务地址为只读排障信息，由 Agent 主机工具修改；不显示人工编号或密钥编辑。
- 每页只有一次“保存并应用”，沿用整套设备参数提交，并在操作栏说明会同时作用于仪表与打印参数；内部校验、持久化、重载及必要回退。参数页显示未提交输入，配置备份页显示实际生效状态与手动保留的备份，不增加用户草稿／待应用操作。
- 生效版本、时间、仪表／打印状态与手动备份分别呈现；保存应用、重连及恢复不新增备份，恢复须先比较两类参数并明确确认。离线只能查看，创建／恢复禁用，删除及管理操作沿用维护管理权限。队列读取失败显示错误，不以 Server 主机队列替代。
- 应用结果区分成功、拒绝、未知、已回退及回退失败；失败／未知保留输入并先核实，成功后读取实际值。切换页签保留未提交编辑，错误反馈紧邻操作栏。设备启停／重载、保存应用、校准样张和备份增删／恢复的临时结果复用全局 toast，右上角浮动、自动消失并可点击 × 提前关闭；待核实作业使用警告提示，持续故障仍在诊断或表单区域展示。
- “启动／停止／重载设备”控制设备执行，Agent 主进程常驻；离线或不支持维护时呈现真实状态，不虚构配置。仪表当前数据须新鲜，过期读数不冒充当前重量；串口权限提示使用 Agent 实际账号。
- 打印诊断将“暂无可读取错误”兼容为无错误提示；真实错误显示警告，维护连接离线或运行／作业状态未确认时明确提示未知，不显示检查成功。状态只代表最近一次检查，不代表实际纸面合格。
- CUPS 重启、队列恢复、校准样张放在打印区，设备执行控制放在总览；采用中文动作名，保留动作权限、作业核实与审计。未知打印先核实，维护恢复不自动重放。

校准提示按“先节长 → 再位置 → 必要时缩放”，明确偏移方向、实际生效值与默认值的区别；具体参数范围及实物要求引用设备规格，不在页面文档重复定义。

## 验证入口

按改动执行前端 lint／build 与 `test:local-management`，关注单次应用、小数节长、手动备份增删查与恢复、历史备份保留、离线只读、Agent 队列、未知作业、只读权限、页签键盘、日志记录及 390px 布局。对应软件和现场完成度由状态页及交付记录维护。
