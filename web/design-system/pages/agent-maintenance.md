# 设备维护页面

适用路由：`/system/agent-maintenance`。本页为 Detail Page、Standard Form Page 和 Standard List Page 的组合变体，沿用 MASTER 中的后台规范。

## 视觉与布局

- 沿用背景 `#F5F7FA`、面板 `#FFFFFF`、边框 `#E5E7EB`、正文 `#1F2937`、辅助文字 `#6B7280`、操作蓝 `#1677FF` 对应的现有 token；状态色仅表达实际状态。
- 沿用后台字体栈，正文 14px、卡片标题 16px；重量和时间使用等宽数字，内容左对齐。
- 页面布局为“标题与刷新 → 最近检查时间 → 四个业务页签 → 当前内容”。复用 `SectionTabs` 的选中态、方向键、Home / End 和键盘焦点规则。
- 总览使用紧凑的四项服务状态条，下方为现场诊断和设备执行控制；设备页按仪表、打印、摄像头分区。桌面仪表与打印并排，窄屏自然堆叠。
- 维护记录复用 `DataTableCard` 和 `TableToolbar`；窄屏仅表格内部横向滚动。日志使用独立的可滚动文本区，保留换行。

## 配置与操作

- 复用 `FormSection`、`Field`、`Input`、`Select`，按服务连接、称重仪表、打印与校准、摄像头与识别分组，提供页内定位链接。
- 配置状态前置，区分表单未保存修改、已保存待应用草稿和运行配置。底部粘性操作栏统一承载恢复、保存草稿、保存并应用及操作反馈。
- 切换页签和刷新状态保留当前编辑；保存、应用或恢复后按实际结果重新读取配置。敏感字段不回显，允许录入替换值。
- 将 CUPS 重启、队列恢复和校准打印放在打印区；设备控制保留在总览。维护确认中使用中文动作名称，沿用原有权限、作业核实与 API 契约。
- 未知与异常分别展示。仪表重量仅在设备执行中且仪表数据可用、新鲜时展示，零值显示为 `0 吨`，不把旧读数作为当前重量。

## 软件验证

执行 `task frontend:lint`、`task frontend:build` 和 `npm --prefix web run test:standalone-management`。浏览器回归使用接口夹具，覆盖原有权限和保存应用流程，以及页签键盘操作、未保存输入保留、零重量、记录与日志、记录空态、桌面及 390px 窄屏布局；不代表现场设备验收。
