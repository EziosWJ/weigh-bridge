# 设备维护页面覆盖规则

适用 `/system/agent-maintenance`，采用 Detail、Standard Form 与 Standard List 组合变体，沿用 MASTER 后台规范。职责及失败规则见[设备规格](../../../docs/requirements/local-device-maintenance-spec.md)，相机、识别及视频设置使用[独立摄像头页](cameras.md)。旧页面说明存于[演进档案](../../../docs/history/ui/agent-maintenance-page-evolution.md)，实际验证见[当前状态](../../../docs/next.md)。

## 视觉与布局

沿用背景 `#F5F7FA`、面板 `#FFFFFF`、边框 `#E5E7EB`、正文 `#1F2937`、辅助 `#6B7280`、操作 `#1677FF` 对应 token；状态色表达实际状态。正文 14px、卡片标题 16px，重量和时间用等宽数字，内容左对齐。

页面按“标题与刷新 → 最近检查时间 → 四个业务页签 → 当前内容”组织。SectionTabs 支持方向键、Home／End 和可见焦点。总览用紧凑服务状态条、诊断和设备执行控制；设备页按仪表、打印队列与校准分区，桌面并排、窄屏堆叠。记录使用 DataTableCard／TableToolbar，表格局部横向滚动；日志使用保留换行的独立滚动文本区。

## 参数与结果

- FormSection、Field、Input、Select 只承载串口、波特率、Agent CUPS 队列、单据节长、水平／垂直偏移、缩放及高级宽度。业务地址为只读排障信息，由 Agent 主机工具修改；不显示人工编号或密钥编辑。
- 只有一次“保存并应用”，内部校验、持久化、重载及必要回退。页面显示未提交输入、实际生效状态及成功备份，不增加用户草稿／待应用操作。
- 生效版本、时间、仪表／打印状态与 Server 成功参数副本分别呈现；备份滞后如实提示，恢复须人员明确发起。队列读取失败显示错误，不以 Server 主机队列替代。
- 应用结果区分成功、拒绝、未知、已回退及回退失败；失败／未知保留输入并先核实，成功后读取实际值。切换页签、刷新状态保留未提交编辑，反馈紧邻操作栏。
- “启动／停止／重载设备”控制设备执行，Agent 主进程常驻；离线或不支持维护时呈现真实状态，不虚构配置。仪表当前数据须新鲜，过期读数不冒充当前重量；串口权限提示使用 Agent 实际账号。
- CUPS 重启、队列恢复、校准样张放在打印区，设备执行控制放在总览；采用中文动作名，保留动作权限、作业核实与审计。未知打印先核实，维护恢复不自动重放。

校准提示按“先节长 → 再位置 → 必要时缩放”，明确偏移方向、实际生效值与默认值的区别；具体参数范围及实物要求引用设备规格，不在页面文档重复定义。

## 验证入口

按改动执行前端 lint／build 与 `test:local-management`，关注单次应用、小数节长、备份恢复、Agent 队列、未知作业、只读权限、页签键盘、日志记录及 390px 布局。对应软件和现场完成度由状态页及交付记录维护。
