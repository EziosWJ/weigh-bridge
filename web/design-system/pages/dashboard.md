# 系统概览

采用 Detail Page 的只读摘要与 ContentCard 分组变体，组合小型列表；复用 ContentCard、DataTable、StatusTag、Button 与 EmptyState，不新增通用页面骨架。页面顶部仅保留右侧刷新按钮，隐藏可视标题、说明和统计日期／更新时间行，保留供屏幕阅读器使用的标题。

- 使用既有蓝灰 Token、14px 正文、等宽数字、弱阴影；四项业务指标在桌面四列、平板两列、窄屏单列。
- 中部待回磅列表与设备摘要在宽屏按 2:1 排列，同排卡片上下边缘对齐，按内容自然撑高；其他宽度纵向排列。表格在模块内横向滚动，首次称重时间与隔日标签不拆字。
- 设备摘要以模块实际宽度适配：至少 640px 时四列，否则两列。每项只包含图标、名称、状态和必要短说明，用细分隔线组织；网格填满可用高度，底部只显示最近读取时间，不提供维护快捷入口。
- “采集中”只说明最近读取的仪表状态；不显示正式称重就绪结论。强制抓拍关闭为中性策略说明，隔日任务为中性标签。未知、未配置、离线、失败分别表达；相机连通性没有依据时明确未检测。
- 业务、仪表、打印、摄像头分别加载；旧请求迟到不覆盖刷新结果，失败清除旧结果。刷新只发起 GET 查询，页面与区域保持原有 RBAC。

数据口径见[总规格](../../../docs/requirements/standalone-site-spec.md#系统概览)。
