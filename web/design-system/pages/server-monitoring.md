# 服务器监控

`/monitor/server` 使用 Detail Page 变体：复用 PageHeader、ContentCard、StatusTag、DetailItem 与 DataTable，展示一台宿主机的实时只读详情。摘要后展示趋势；下方将文件系统、块设备、网卡、GPU 与进程整合为同一区域的 Tab 切换。每区域保留独立采集状态和有效时间；趋势资源/设备选择靠近图表，不引入通用管理列表的分页或 CRUD 操作。

桌面概览与进程排行采用两列，窄屏降为单列；设备表格保持横向滚动。使用现有中性色与状态色，每5秒更新数据，不增加视觉动画。

CPU/内存摘要使用等高分区，主占用值与细条进度标尺突出当前利用率；CPU逐核以紧凑四列条带展示分布，内存总量/已用/可用独立对齐，避免复合大数字换行。沿用现有主色、中性色和高占用语义色，空值保留采集中状态。

资源详情采用带图标与主色下划线的横向 Tab，默认文件系统；过期、不支持或采集不完整的区域在 Tab 上保留提示点，方便发现未打开分区的问题。窄屏 Tab 可横向滚动；支持方向键、Home/End 切换与明确的键盘焦点，切换不停止后台采样或刷新。

文件系统默认采用容量概览：保留根挂载与持久存储，隐藏内存/只读映像及 WSL、Docker 运行时挂载，同一设备来源与文件系统类型保留路径最短的代表挂载。设备名不同的存储分别展示，不累计重复容量；同样筛选用于文件系统趋势设备选择。“显示全部挂载点”恢复原始采集列表，方便排查绑定挂载、临时文件系统等细节；采集口径与后台异常判断保持原契约。
