用户要求独立于后台的三套纯页面，先比较后选择；本轮不接入业务状态、模拟流程、设备或正式记录。

2026-10-18 用户选定 B「现场监看台」，现有工作台的视觉落地以 [称重页面覆盖说明](weighing.md) 顶部当前视觉章节为准；本入口保留三套静态方案供回看。

入口：`/weighing/design-demo`，通过 `?scheme=a`、`?scheme=b`、`?scheme=c` 切换。入口使用固定示例数据，不需要登录，不读取业务缓存和 API。现有工作台入口及鉴权保持原样。

这些页面是 Form / Detail 作业变体的视觉探索，不建立通用页面 Pattern。用户已明确允许脱离后台主规范；独立 CSS 作用域保留不同布局、色彩和字体，后台组件与全站 token 不变。

设计自检：以仪表、现场画面、车辆重量横栏分别承担三个方案的唯一视觉重点，移除无关统计卡片、装饰性渐变和进场动画。资料左对齐，数字采用等宽数字；车辆图片使用仓库现有静态素材并标识为示例。窄屏纵向排列。

所有按钮仅作样式展示；方案切换是唯一用于对比的导航，不表示称重、识别或采集已执行。按用户本轮范围，只要求前端编译通过，不增加业务测试。

验证：`task frontend:build` 通过。临时 Vite 与 Playwright 检视三套页面在 1366×768 和 390×844 下的渲染，无横向溢出及页面运行错误，桌面主操作均可见；截图保存在 `/tmp/workbench-design-{a,b,c}.png` 及对应 `-mobile.png`。验证后已关闭临时服务和浏览器。
