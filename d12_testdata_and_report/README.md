## 校验规则

868 帧覆盖 52 种数值、61 种不同整帧及动态／非动态状态，均满足：

```python
cks = sum(frame[:16]) & 0xff  # 含 STX，不含 CR 和 CKS
```

对比的包含 CR 累加、包含 CR 的 7 位补码、包含 CR 的 8 位补码算法均为 0/868 匹配。本机本次零值、正值毛重及动态状态报文已验证上述累加规则；负值、非零皮重、净重及其他固件未覆盖。原始采集记录中的 `checksumStatus` 保持采集当时的 `unconfirmed_algorithm`，本分析单独给出新验证结果，原始记录不改写。
